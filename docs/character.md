# キャラクターの画面

`#menu` を使う画面の 1 つ（`menuState.mode = 'char'`）。コードは `src/ui.js`。`#menu` の画面に共通のしくみ（ポップアップ・装備の付け替え・ボタン）は [menu.md](menu.md)、開き方・閉じ方・キーの登録表は [screens.md](screens.md)。

- キャラクターの画面（`'char'`）は Tab キーか HUD の左上の仲間の欄のクリックで開く（一時停止画面の「キャラクター」ボタン・一時停止中の C キーでも）。フィールドの HUD には顔・名前・レベル・HP・MP しか出さないので、それ以外はこの画面で見る。見出しに所持金。一時停止から開いたときは、閉じると一時停止画面に戻る（`closeMenu` が `showPause` を呼ぶ）。中身は**タブ**に分ける（下の「タブ」）

## タブ

全部を 1 枚に並べると見にくいので、キャラクターの画面はタブに分ける（ほかの `#menu` の画面にはタブがない）。

| タブ（`CHAR_TABS` の id） | 名前（`data/text.js` の `menu.tabs`） | 出すもの |
|---|---|---|
| `status` | ステータス | 左に顔の絵・名前・レベル・HP・MP（ゲージつき）・経験値（次のレベルまで）・撃破数・状態（安全地帯／休息中／戦闘中）・ターン数・今いるゾーンと敵レベル（`profileHtml`）、右に「つよさ」（全ステータスを「基礎能力値」（行動で伸びる）と「ステータス」（基礎能力値と装備で決まる）の 2 つに分けて出す。`strengthHtml`。行動で伸びるステータスにマウスを重ねると、行の中に潜在と小数点以下まで入れた値が出る `growthTipHtml`。[growth.md](growth.md)） |
| `equip` | 装備 | 装備中・装備品（持ち物の装備）・「つよさ」。装備をクリックするとポップアップで付け替え・外す・捨てる（道具一覧と同じ）。付け替えるとつよさがすぐ変わる |
| `items` | 持ち物 | 道具と素材。クリックで詳細のポップアップ（ここでは「使う」は出ない。使うのは道具一覧） |
| `quest` | クエスト | 受けているクエストの進み具合（目標の種類の `short` と数。報告できるものは緑。`questsHtml`。[quests.md](quests.md)） |

- 切り替え: タブのボタンのクリック（`data-act="tab"`）、← → で隣のタブ（端から反対の端へ回る）、1〜4 でそのタブ（`tabKeys`）。切り替えは行動にならず、開いているポップアップと選んだ装備は消える（`switchTab`）
- 開いているタブは `menuState.tab`。閉じても覚えていて、次に開くと同じタブ（セーブはしない。はじめは `status`）
- しくみ: 画面の定義に `tabs: CHAR_TABS` を書くとタブを出す（`renderTabs` が `#menuTabs` にボタンを作り、`#menuBody` の `data-tab` に今のタブを入れる）。`index.html` の `#menuBody` の中のまとまりには、どのタブで出すかを `data-sec`（空白区切り）で書いてあり、`style.css` が `data-tab` と合わないまとまりを隠し、タブごとの列の幅を決める。タブのない画面（`data-tab` がない）ではどれも出す
- タブを足すとき: `CHAR_TABS` に id を足し、`data/text.js` の `menu.tabs` に名前、`index.html` で出したいまとまりの `data-sec` に id、`style.css` に隠す決まり（`.menu-body[data-tab="id"] [data-sec]:not([data-sec~="id"])`）と列の幅を足す
