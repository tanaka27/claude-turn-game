# 戦闘（技・予告）

技の定義形式、主人公の技、敵の技の予告、判定の仕組み。
技を使う道（どのキャラも同じ `useSkill`）と、再使用待ち・MP の決まり（主人公と敵で違う）は [skill-use.md](skill-use.md)。
ステータスとダメージ計算（物理・術）は [damage.md](damage.md)。
主人公の技（スキル）の定義は `data/skills.js`（どのレベルで覚えるか・どのキーに置くかは `data/player.js`）、敵の技は `data/enemies.js`。コードは `src/combat.js`。
スキルを覚えている・スキル欄（キー）のしくみは [skill-use.md](skill-use.md) の「覚えているスキルとスキル欄」。
行動の順番は [turn.md](turn.md)。

## 技の定義形式

距離・範囲はマス、時間は行動回数。書き方の説明は `data/skills.js` の先頭にもある。スキル（`data/skills.js`）には、ほかに英字の `id`（覚えたスキル・スキル欄・再使用待ち・セーブはこれで指す）がある。敵の技には `id` はない。

| 項目 | 意味 |
|---|---|
| type | `melee`（自分のまわり）/ `projectile`（まっすぐ飛ぶ弾）/ `lob`（指定したマスへ投げる。壁を越える）/ `dash`（移動）/ `buff`（自分を強化する。狙わずにすぐ使う） |
| shape | melee の形。`fan`（扇形）/ `circle`（円）/ `line`（直線） |
| range | 射程（マス）。fan / circle は半径（マスの中心どうしの距離）、line / projectile は長さ（縦横の大きいほうで数える。斜めも同じ歩数まで届く）。となりのマスだけなら 1.5 |
| angle | fan の角度（度） |
| width | line / projectile の幅（マス。今は 1 だけ） |
| charge | 0 なら使ったその場で判定。1 なら予告を出し、使った者の次の行動で判定 |
| cooldown | 再使用までの行動回数（N なら N 回の行動に 1 回使える）。スキル加速で短くなる（敵は四捨五入して最低 1。[skill-use.md](skill-use.md)） |
| mp | 技が使う MP（主人公も敵も。省略時 0）。足りないと使えない |
| kind | `physical`（物理、省略時）/ `magic`（術） |
| power | 物理の威力倍率 |
| base / matkRate | 術の固定ダメージ / 術攻撃力の効き（省略時は `params.js` の `magic.matkRate`） |
| pierce | 弾が貫通する |
| count / spread | 同時に撃つ弾の数 / 広がる角度（度） |
| castRange / radius / scatter | lob の最大射程 / 着弾範囲の半径 / 複数投げるときの散らばり（どれもマス） |
| buff / duration | buff の技がかける強化（`data/buffs.js` のキー） / 続く行動回数 |

## 主人公の技（`data/skills.js`。キーと覚えるレベルは `data/player.js`）

| キー | id | 名前 | 内容 | 再使用 | 消費 MP | 種類・威力 | 覚える |
|---|---|---|---|---|---|---|---|
| 敵へ移動 | - | 斬撃 | 通常攻撃（`PLAYER.basicAttack`）。となりの敵 1 体（攻撃範囲（槍）があれば 1 + 攻撃範囲 マス先まで、いちばん近い敵 1 体。[crafting.md](crafting.md)） | - | - | 物理 1.0 | はじめから |
| 1 | shockwave | 衝撃波 | 9 マス貫通する直線の弾 | 5 | 3 | 物理 1.4 | Lv1 |
| 2 | whirlwind | 旋風斬 | 自分のまわり半径 2.3 マス | 6 | 4 | 物理 1.6 | Lv3 |
| 3 | meteor | メテオ | 8 マス以内のマスへ。半径 2.3 マス | 10 | 8 | 術 base 6 | Lv6 |
| 4 | dash | ダッシュ | 狙った向き（8 方向）へ最大 4 マス一気に進む（1 行動） | 6 | 2 | - | Lv1 |
| 5 | battleAura | 闘気 | 自分に「攻撃力アップ」（こうげき力 ×1.3）を 6 行動のあいだかける。キーを押すとすぐ使う（狙わない） | 12 | 4 | 強化 | Lv1 |

「キー」は `PLAYER.skillSlots`（スキル欄のはじめの並び）、「覚える」は `PLAYER.learnAtLevel`（はじめの覚え方。[progression.md](progression.md)）。

主人公のスキルはどれも予告なし（使ったその場で当たる）。技を使う道はどのキャラも同じなので、仲間・敵も同じ形の技（ダッシュ・強化を含む）を使える（[skill-use.md](skill-use.md)）。

### 強化・弱体（バフ・デバフ。コードではまとめて buff）

- 種類は `data/buffs.js` の `BUFFS`（表示名・変えるステータス `stat`・倍率 `mult`・アイコンの字 `icon` と色 `color`）。`mult` が 1 より大きいと強化（アイコンに緑の ▲）、1 より小さいと弱体（赤の ▼）。どれをかけて何行動続くかは技（`type: 'buff'`、`buff`、`duration`）に書く
- 今のデータにあるのは強化 1 つだけで、かける手段も自分にかける技（`type: 'buff'`）だけ（道具の効果 `addBuff` でもかけられるが、今の道具には使っていない。[consumables.md](consumables.md)）。データにあるのは主人公の闘気だけだが、技を使う道は同じなので敵・仲間も強化の技を自分に使える（`castBuff`。主人公以外は文の頭に名前が付く。テストは `tests/skills.test.js`）。弱体の種類・相手にかける技はまだない（しくみはどのキャラにも効く。テストは `tests/effects.test.js` で自分の弱体を足して確かめている）

| キー | 名前 | 効果 | アイコン |
|---|---|---|---|
| atkUp | 攻撃力アップ | こうげき力 ×1.3（物理のダメージが上がる。術には効かない） | 橙の「攻」に緑の ▲ |

- 戦うキャラ（主人公・敵・仲間）はみな `buffs: [{ id, left, fresh }]` を持つ。`left` は残りの行動回数で、**かかったキャラ自身の行動**で数える（`tickBuffs`、行動の後始末 `endTurn` から）。0 で外れて、メッセージ欄に「〇〇の効果が切れた。」（主人公）／「□□の〇〇の効果が切れた。」（ほかのキャラ。□□はキャラの名前）と出る
- `addBuff(u, id, n, src)`: u に n 行動かける。`src`（かけた者。省略時は u 自身）が u なら、かけた行動の終わりでは減らさない（`fresh`）。`duration: 6` の闘気なら、使ったあとの 6 行動のあいだ効く。ほかの者がかけたときは、u の次の行動から数える（n 行動のあいだ効く）
- 同じものをもう一度かけると、残りの長いほうになる（重ねがけはしない）
- かけたとき・切れたとき・消したときに `refreshStats` で計算し直す（計算の順番と HP・MP の合わせ方は [damage.md](damage.md)）。ステータスから決まるものはすべて変わる: 速度が下がれば行動の回数が減り、最大 HP が下がれば今の HP も切られ（切れても戻らない）、こうげき力が下がれば与えるダメージが減る。装備（敵・仲間は `gear`）の分は倍率を受けない
- 消えるとき（`clearBuffs`）: 主人公は倒れて復活したとき（倒れている間はアイコンを残す）、主人公以外は倒れたとき（`kill`）、敵は諦めて帰り着いて全回復したとき。セーブには入れない（続きから遊ぶと強化はない）
- アイコンは、主人公は左上の欄の名前の右（マウスを重ねると説明）とフィールドの頭上、敵・仲間は頭上の HP バーのさらに上（`drawBuffRow`。説明は出ない）
- これから足す別の種類の効果（毒などの行動ごとのダメージ、スタン）: 行動ごとの効き目は `tickBuffs`（`endTurn` から呼ばれる）に、「行動できない」の判定は `runUntilInput`（`control` を呼ぶ前。行動の代わりに `endTurn` だけ通す）と主人公の入力（`src/player.js`）に足す

### MP

- スキルを使うと `mp` だけ MP が減る（`useSkill`）。主人公は今の MP（切り捨て）が足りないと使えず、キーを押したとき・使おうとしたときにメッセージ欄に「MP が足りない（〇〇は MP N、今 M）。」と出る（`enoughMp` / `logNoMp`、文は `src/player.js`）。再使用待ちの判定が先。敵の比べ方は [skill-use.md](skill-use.md)
- 再使用待ちはそのまま残す。MP を入れたときに、MP でも回数が限られるようになったので、旋風斬を 7 → 6、メテオを 14 → 10 に短くした
- 最大 MP は Lv1 で 12（MP を使うと伸びる。[growth.md](growth.md)）。MP は時間で回復する（MP再生 0.2 / ターン、休息中はさらに最大MP の 2% / ターン。[turn.md](turn.md)）。Lv1 なら衝撃波を 4 回続けて撃つと尽き、休息中なら 1 発分を約 7 ターンで取り戻す

## 敵の技の予告

`charge: 1` の技は、使うと範囲のマスが赤く塗られ（予告）、**その敵の次の行動**で判定する（今のデータでは敵の技だけにあるが、しくみはどのキャラにも効く。出すのは `runUntilInput` の `releaseCharge`。[skill-use.md](skill-use.md)）。
その間に範囲の外へ出れば当たらない。予告には「あと N」（それまでに主人公が動ける回数）を出し、1 のときは点滅する。
予告中の敵は頭上に「!」が付き、メッセージ欄に「〇〇は△△の構えをとった。」と出る。

範囲は予告を出したときに決まる（狙ったマスも、lob の散らばりもそのとき決める）。予告中の敵を倒すと予告は消える。

## 仕組み

- `planAttack(u, atk, ax, ay)`: 技の範囲を決める。戻り値は範囲のマス（`tiles`、`keys`）、弾の通り道（`rays`）、着弾点（`centers`）
  - melee の fan / circle: 半径内で、角度に入り、攻撃を遮る地形でなく、視線が通るマス
  - line / projectile: `rayTiles` で直線のマス（攻撃を遮る地形の手前まで）
  - lob: 射程より遠ければ同じ向きで射程いっぱいのマスにする。着弾点の半径内で、着弾点から視線が通るマス（着弾点が壁の中なら視線は見ない）
- `resolveAttack(h)`: 判定。範囲のマスにいる相手（使った者の陣営から見た敵 `opponents(h.faction)`。敵の技なら主人公の陣営のキャラ全員）に `dealDamage`（同じ相手には 1 回だけ）。projectile は弾の通り道を近い順に見て、`pierce` でなければ最初に当たった相手で止まる
- `startCharge` / `cancelCharge` / `releaseCharge`: 予告を `hazards` に出す・消す・出す（判定する）。使った者の `charging` に持つ
- `rollDamage(src, tgt, a)`: 技 `a` の `kind` で物理か術の式を選び、`{ dmg, crit }` を返す
- `dealDamage(src, tgt, a, what)`: `rollDamage` でダメージを決め、浮かぶ数字、メッセージ欄（`damageLine`）。待機中の敵は追跡を始める（`aggro`）。HP が 0 以下なら `kill`（主人公・敵・仲間で分かれる）。色・文・倒れたときの分かれ方は [units.md](units.md)
- 技を使うのはどのキャラも `useSkill(u, sk, tx, ty, plan)`（[skill-use.md](skill-use.md)）。主人公のスキルは `castSkill`（`src/player.js`）が再使用待ち・MP を確かめて（足りなければ文を出す）`useSkill` を呼び、使えたら `endPlayerAction`。狙っている間は同じ `planAttack` の範囲を白く表示する
