# 武器種と鍛冶屋で作る

武器の種類（武器種）と、鍛冶屋でモンスターの素材から武器を作るしくみ。装備のほかの決まり（レア度・追加性能・価値・店の品ぞろえ）は [items.md](items.md)、鍛冶屋の画面のしくみは [menu.md](menu.md)。データは `data/items.js`（`ITEMS.slots.weapon.types` / `recipes` / `craftRarities` / `smiths[*].recipes`）、コードは `src/items.js`（`makeItem` / `craftBlock` / `craftItem`）と `src/ui.js`（鍛冶屋の画面）。

## 武器種（`ITEMS.slots.weapon.types`）

武器はどれも種類を 1 つ持つ（装備の `type`）。基本性能と名前は種類で決まる。防具・装飾品には種類はない。
店・敵が落とす・クエストの報酬の武器の種類はくじ（4 つが同じ確率）。クエストの報酬は `item.type` で決めることもできる。はじめの武器は剣（`data/player.js` の `startEquip.weapon.type`）。

| 種類 (`type`) | 基本性能（`[Lv1 の値, 1 レベルごとの増加]`） | 名前（2 レベルごとに変わる） | 特徴 |
|---|---|---|---|
| 剣 (`sword`) | こうげき力 1.2 + 0.6/Lv | 木の剣 → 銅の剣 → 鉄の剣 → 鋼の剣 → 騎士の剣 → 魔鋼の剣 → 竜骨の剣 → 聖剣 | 釣り合い型（2026-11-26 より前の武器と同じ） |
| 短剣 (`dagger`) | こうげき力 0.8 + 0.4/Lv、すばやさ 3 + 0.3/Lv、会心倍率 0.06 + 0.008/Lv | ナイフ → 銅の短剣 → … → 聖なる短剣 | こうげき力は低いが、速度（行動の回数）と会心が上がる |
| 斧 (`axe`) | こうげき力 1.8 + 0.9/Lv、すばやさ −3 − 0.3/Lv | 手斧 → 銅の斧 → … → 戦斧 → … → 聖斧 | こうげき力が高いが、重くて すばやさ（速度）が下がる |
| 杖 (`staff`) | こうげき力 0.4 + 0.2/Lv、術攻撃力 1.6 + 0.8/Lv | 木の杖 → 樫の杖 → 魔術師の杖 → … → 聖杖 | 術（メテオ）が強くなる |

- 基本性能の値にはレア度の倍率（`mult`）をかける。負の値（斧のすばやさ）には倍率をかけない（レア度が高いほど重くはならない）。丸めは正の値と同じで、負のまま丸める（`roundStat`）
- 追加性能は、その種類の基本性能と同じステータスは付かない（短剣には すばやさ・会心倍率 の追加性能は付かない）
- 装備の詳細の「基本性能」は種類の `base`。種類の違う武器を選んだときは、装備中の武器にだけある基本性能を基本性能の欄の最後に薄く出す（杖から剣に替えると 術攻撃力 が「-」と差で出る）
- 道具一覧・店では、装備の部位のところに武器種を出す（「短剣 Lv3」）
- 種類を足す: `types` に `{ label, base, names }` を 1 つ足す。キーはセーブに残るので変えない（変えるならセーブの版を上げる）。起動時のデータの確認で、`label`・`names`・基本性能のステータスがあるかを調べる。今はない種類の武器は、セーブを読むときに捨てる
- 武器種は今は数値の違いだけ。通常攻撃の形（槍・弓の届く距離）や、武器種でしか使えないスキルはまだない

## 鍛冶屋で作る（`recipes`）

鍛冶屋の画面の「武器を作る」で、その鍛冶屋の作り方（`smiths[*].recipes`）から武器を作る。素材と代金を使い、作った武器は持ち物に入る（持ち物がいっぱいなら作れない）。

- 作った武器の名前・武器種・装備レベルは作り方で決まる（自分のレベルには合わせない）。装備には作り方のキー `recipe` も残る
- レア度はくじ（`craftRarities`）: アンコモン 80%・レア 17%・エピック 3%。基本性能の倍率と追加性能の数はレア度で決まり、追加性能の種類と値の揺れはランダム（店・落とし物と同じ `makeItem`）
- 価値（売値）は店・落とし物の装備と同じ式（装備レベルとレア度）
- 作れないとき（`craftBlock` の理由）: 素材が足りない、お金が足りない、持ち物がいっぱい。このときは何も減らない
- 作ると、集めるクエストに `questEvent('materials')` を伝える（素材が減るので）

### 作り方を足す

1. `data/items.js` の `recipes` に `{ name, slot, type, level, materials, gold }` を 1 つ足す（`type` は種類のある部位（武器）だけ）
2. 作れる鍛冶屋の `recipes` にキーを書く
3. 上の表を直す

起動時のデータの確認で、作り方の部位・種類・`level`（1 以上の整数）・`gold`（0 以上）・素材（`materials` にあるか、数が 1 以上の整数か）、鍛冶屋の `recipes` のキーがあるか、どの鍛冶屋でも作れない作り方がないか、`craftRarities` のレア度と `weight` を調べる。
