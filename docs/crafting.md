# 武器種と鍛冶屋で作る

武器の種類（武器種）と、鍛冶屋でモンスターの素材から武器を作るしくみ。装備のほかの決まり（レア度・追加性能・価値・店の品ぞろえ）は [items.md](items.md)、鍛冶屋の画面のしくみは [menu.md](menu.md)。データは `data/items.js`（`ITEMS.slots.weapon.types` / `recipes` / `craftRarities` / `smiths[*].recipes`）、コードは `src/items.js`（`makeItem` / `craftBlock` / `craftItem`）と `src/ui.js`（鍛冶屋の画面）。

## 武器種（`ITEMS.slots.weapon.types`）

武器はどれも種類を 1 つ持つ（装備の `type`）。基本性能と名前は種類で決まる。防具・装飾品には種類はない。
店・敵が落とす・クエストの報酬の武器の種類はくじ（6 つが同じ確率）。クエストの報酬は `item.type` で決めることもできる。はじめの武器は剣（`data/player.js` の `startEquip.weapon.type`）。

| 種類 (`type`) | 基本性能（`[Lv1 の値, 1 レベルごとの増加]`） | 名前（2 レベルごとに変わる） | 特徴 |
|---|---|---|---|
| 剣 (`sword`) | こうげき力 1.2 + 0.6/Lv | 木の剣 → 銅の剣 → 鉄の剣 → 鋼の剣 → 騎士の剣 → 魔鋼の剣 → 竜骨の剣 → 聖剣 | 釣り合い型（2026-11-26 より前の武器と同じ） |
| 短剣 (`dagger`) | こうげき力 0.8 + 0.4/Lv、すばやさ 3 + 0.3/Lv、会心倍率 0.06 + 0.008/Lv | ナイフ → 銅の短剣 → … → 聖なる短剣 | こうげき力は低いが、速度（行動の回数）と会心が上がる |
| 斧 (`axe`) | こうげき力 1.8 + 0.9/Lv、すばやさ −3 − 0.3/Lv | 手斧 → 銅の斧 → … → 戦斧 → … → 聖斧 | こうげき力が高いが、重くて すばやさ（速度）が下がる |
| 杖 (`staff`) | こうげき力 0.4 + 0.2/Lv、術攻撃力 1.6 + 0.8/Lv | 木の杖 → 樫の杖 → 魔術師の杖 → … → 聖杖 | 術（メテオ）が強くなる |
| 槍 (`spear`) | こうげき力 1.0 + 0.5/Lv。固有で 攻撃範囲 +1（`fixed`） | 木の槍 → 銅の槍 → … → 聖槍 | 通常攻撃が 2 マス先まで届く（いちばん近い敵だけ。下の「攻撃範囲」） |
| 弓 (`bow`) | こうげき力 0.6 + 0.3/Lv。固有で 射程 5（`fixed`）。矢を撃つ（`ammo`） | 木の弓 → 短弓 → 狩人の弓 → 長弓 → 騎士の弓 → 魔鋼の弓 → 竜骨の弓 → 聖弓 | 射程の中の敵を矢で撃つ。矢の攻撃力を足すぶん、弓のこうげき力は低い（下の「弓」） |

- 基本性能の値にはレア度の倍率（`mult`）をかける。負の値（斧のすばやさ）には倍率をかけない（レア度が高いほど重くはならない）。丸めは正の値と同じで、負のまま丸める（`roundStat`）
- `fixed` は種類だけが持つ決まった値の能力（槍の 攻撃範囲 +1、弓の 射程 5）。レベルにもレア度にも左右されず、そのまま装備の `stats` に入る。追加性能の候補には入れない。画面では基本性能の欄に出す
- 追加性能は、その種類の基本性能と同じステータスは付かない（短剣には すばやさ・会心倍率 の追加性能は付かない）
- 装備の詳細の「基本性能」は種類の `base`。種類の違う武器を選んだときは、装備中の武器にだけある基本性能を基本性能の欄の最後に薄く出す（杖から剣に替えると 術攻撃力 が「-」と差で出る）
- 道具一覧・店では、装備の部位のところに武器種を出す（「短剣 Lv3」）
- 種類を足す: `types` に `{ label, base, names }`（あれば `fixed`・`ammo`）を 1 つ足す。キーはセーブに残るので変えない（変えるならセーブの版を上げる）。起動時のデータの確認で、`label`・`names`・基本性能と `fixed` のステータスがあるか（`fixed` が `base` と重なっていないか）を調べる（`ammo` の種類は `fixed.range` があるか、矢の道具があるか）。今はない種類の武器は、セーブを読むときに捨てる
- 武器種でしか使えないスキルはまだない

### 攻撃範囲（`reach`、槍）

ステータス 攻撃範囲（`data/stats.js` の `reach`）の数だけ、通常攻撃が遠くまで届く（届くのは 1 + 攻撃範囲 マス先まで）。持つのは装備だけ（主人公の Lv1 の値にはなく、つよさには 0 と出る）。今は槍の 攻撃範囲 +1 だけ。

- 敵のいる向き（縦・横・斜めの 1 歩）へ動こうとしたとき（キー・となりのマスのクリック）、その向きに 1 + 攻撃範囲 マス先までを近い順に見て、**いちばん近いキャラ**が敵ならそのキャラだけに通常攻撃する（主人公は動かない。`reachTarget`、`src/player.js`）。奥にいる敵には当たらない
- いちばん近いキャラが味方（仲間）・NPC なら届かない（そのまま、今までどおり進めない・話しかける）。届く敵がいなければ今までどおり 1 歩動く
- 攻撃を遮る地形（壁など。水場は遮らない）の先には届かない。2 マス目からは、斜めに進むとき角を挟む 2 マスが両方とも遮るなら止まる（直線 `rayTiles` と同じ決まり）
- 縦・横・斜めにまっすぐ並んだ 1 + 攻撃範囲 マス以内の敵をクリックすると、その向きへ攻撃する（間により近い敵がいればそちらに当たる）。それより遠い敵のクリックは今までどおり歩く
- クリックで歩いている途中の 1 歩（`stepTravel`）では離れた敵を突かない（`tryMove(dx, dy, true)`）
- 演出は、主人公から当たった敵までのマスに出す
- 攻撃範囲が効くのは主人公の通常攻撃だけ（スキル・敵・仲間の攻撃には効かない）

### 弓（`ammo`・射程 `range`・矢）

弓（`ammo: true` の武器種）は、矢（`consumables` のうち `arrow` を持つ道具。[consumables.md](consumables.md) の「矢」）を撃つ。撃つのは主人公の通常攻撃のかわり（`shootAt`、`src/player.js`）。

- **撃てる距離**は ステータス 射程（`data/stats.js` の `range`。弓の `fixed` で 5）。縦・横・斜めの歩数（`tileSteps`）で数える。持つのは装備だけ（つよさには 0 と出る）
- **狙い方**:
  - 射程の中で、間を攻撃を遮る地形（壁など。`hasLOS`）で遮られていない敵をクリックすると撃つ。まっすぐ並んでいなくてよい。キャラは矢を遮らない
  - 敵のいる向きへ動こうとしたとき（キー・となりのマスのクリック）は、槍と同じく、その向きに射程マス先までを近い順に見て、いちばん近いキャラが敵なら撃つ（`reachTarget`。手前に味方・NPC がいれば撃たない）。となりの敵も撃つ
  - 射程より遠い敵・壁の向こうの敵のクリックは、今までどおり歩く。クリックで歩いている途中の 1 歩では離れた敵を撃たない
- **ダメージ**: 物理の式で、こうげき力（ちから + 弓 + ほかの装備）に矢の攻撃力（`arrow.atk`）を足す（`atkBonus`、`rollDamage`）。威力は `PLAYER.bowAttack.power`（1.0）。メッセージ欄の技の名前は矢の名前（「木の矢: ウルフに 5 のダメージ」）
- **投擲**: 弓の攻撃は「投擲」（`thrown`）。相手との距離が離れるほど当たりにくい（[damage.md](damage.md) の「投擲の命中」）
- **矢を使う**: 撃つたびに 1 本減る（当たっても外れても）。最後の 1 本を撃つと「矢が尽きた。」と出す
- **使う矢**: 道具一覧で「使う矢にする」を押した矢（`player.arrow`。行動にならない。セーブにも残る）。選んでいない・選んだ矢が尽きたときは、`consumables` に書いた順で先の矢（木の矢 → 鉄の矢 → 鋼の矢）から使う（`currentArrow`、`src/items.js`）
- **矢がないとき**: 離れた敵には撃てない。となりの敵へは素手で殴る（「矢がない！ 素手で殴る。」。技の名前は「素手」。弓のこうげき力は引き、矢の攻撃力も乗らない）
- HUD のスキル欄に、弓を装備しているときだけ「矢」の枠を出す（次に撃つ矢の名前と数。なければ「矢なし」×0）
- 射程・投擲が効くのは主人公の弓の攻撃だけ（敵の飛び道具の技にはまだ付けていない。付けるときは技に投擲のしるしを足して `hitChance` に渡す）

## 鍛冶屋で作る（`recipes`）

鍛冶屋の画面の「武器を作る」で、その鍛冶屋の作り方（`smiths[*].recipes`）から武器を作る。素材と代金を使い、作った武器は持ち物に入る（持ち物がいっぱいなら作れない）。

- 作った武器の名前・武器種・装備レベルは作り方で決まる（自分のレベルには合わせない）。装備には作り方のキー `recipe` も残る
- レア度はくじ（`craftRarities`）: アンコモン 80%・レア 17%・エピック 3%。基本性能の倍率と追加性能の数はレア度で決まり、追加性能の種類と値の揺れはランダム（店・落とし物と同じ `makeItem`）
- 価値（売値）は店・落とし物の装備と同じ式（装備レベルとレア度）
- 作れないとき（`craftBlock` の理由）: 素材が足りない、お金が足りない、持ち物がいっぱい。このときは何も減らない
- 作ると、集めるクエストに `questEvent('materials')` を伝える（素材が減るので）

作り方の表（鍛冶屋ごとの武器・素材・代金）は [crafting-recipes.md](crafting-recipes.md)。

### 作り方を足す

1. `data/items.js` の `recipes` に `{ name, slot, type, level, materials, gold }` を 1 つ足す（`type` は種類のある部位（武器）だけ）。種類の基本性能に性能を足すなら `bonus: { ステータス: [Lv1 の値, 1 レベルごとの増加] }`（器用さの補正のある弓。基本性能と同じくレア度の倍率をかけ、画面でも基本性能の欄に出る）
2. 作れる鍛冶屋の `recipes` にキーを書く
3. [crafting-recipes.md](crafting-recipes.md) の表を直す

起動時のデータの確認で、作り方の部位・種類・`level`（1 以上の整数）・`gold`（0 以上）・素材（`materials` にあるか、数が 1 以上の整数か）、鍛冶屋の `recipes` のキーがあるか、どの鍛冶屋でも作れない作り方がないか、`bonus` のステータス（`data/stats.js` にあり、種類の基本性能・`fixed` と重ならない）と値の形、`craftRarities` のレア度と `weight` を調べる。
