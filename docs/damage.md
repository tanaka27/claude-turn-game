# ステータスとダメージ（物理・術）

ステータスの意味、技の種類（物理と術）、ダメージ計算。
数値は `params.js` の `damage` / `magic` / `derivedStats`、技の `kind` / `power` / `base` は `data/player.js` と `data/enemies.js`。コードは `src/combat.js` の `rollDamage`。
技の範囲・予告は [combat.md](combat.md)。

## ステータス

主人公はドラクエ風（成長は [progression.md](progression.md)）。敵は atk / def / int / mdef / speed / critRate を直接持つ。

| ステータス | 意味 |
|---|---|
| さいだいHP（maxHp） | レベルで上がる |
| さいだいMP（maxMp） | レベルで上がる。スキルを使うと MP が減る（消費 MP は [combat.md](combat.md)） |
| ちから（str） | こうげき力のもと |
| みのまもり（vit） | しゅび力のもと |
| すばやさ（agi） | 速度を決める |
| かしこさ（int） | 術のダメージ・術防御・スキル加速を決める |
| うんのよさ（luk） | 会心率を決める。レベルでは上がらない |
| 会心倍率（critMult） / HP再生（hpRegen、1 ターンごと） / MP再生（mpRegen、1 ターンごと。Lv1 は 0.2） | レベルでは上がらない |
| こうげき力（atk） | ちから + 装備 |
| しゅび力（def） | みのまもり + 装備。物理の被ダメージを減らす |
| 術防御（mdef） | かしこさ × 0.5 + 装備。術の被ダメージを減らす |
| 速度（speed） | 100 + (すばやさ − 20) × 2。行動 1 回 = 100 / 速度 ターン |
| スキル加速（skillHaste） | (かしこさ − 10) × 0.5。スキルの再使用 = 基本 × 100 / (100 + スキル加速) 行動 |
| 会心率（critRate） | うんのよさ × 0.5% |

計算で決まるものの式は `params.js` の `derivedStats`。

## 技の種類（物理と術）

技は `kind` で物理（`'physical'`、省略時）と術（`'magic'`）に分かれる。

| 種類 | 計算に使う | 技 |
|---|---|---|
| 物理 | こうげき力 / しゅび力、技の `power` | 主人公: 斬撃・衝撃波・旋風斬。敵: 火を使うもの以外すべて |
| 術 | かしこさ / 術防御、技の `base`（と `intRate`） | 主人公: メテオ。敵: 火炎弾（サラマンダー）、胞子の雨（森の主）、火炎の息・隕石落とし（魔竜） |

敵のツールチップでは術の技に「（術）」と付く。

## 物理のダメージ計算（ドラクエ式）

```
基礎ダメージ = (攻撃側のこうげき力 / 2 − 防御側のしゅび力 / 4) × 技の威力
基礎ダメージが 1 未満 → 0 か 1（半々。0 は「ミス」）
それ以外         → 基礎ダメージ × 乱数(1 ± 1/16)。四捨五入
会心のとき       → 防御を無視して こうげき力 / 2 × 会心倍率 × 技の威力 × 乱数(1 ± 1/16)。最低 1
```

- 数値は `params.js` の `damage`（`atkRate` 0.5、`defRate` 0.25、`minBase` 1、`variance` 1/16）
- 引き算なので、しゅび力が相手のこうげき力の 2 倍に近づくとほとんど効かなくなる（レベルを上げると弱い敵の攻撃はミスばかりになる）。逆にこうげき力が足りないと、硬い敵（ロックゴーレム・ボス）にはミスが多くなる
- 会心はしゅび力を無視するので、硬い敵ほど会心がよく効く
- 「ミス」でも当たったことにはなる（弾は止まり、待機中の敵は追ってくる。クリックで歩いているのも止まる）

## 術のダメージ計算

```
基礎ダメージ = 技の固定値(base) + 攻撃側のかしこさ × intRate
ダメージ     = 基礎ダメージ × 50 / (50 + 防御側の術防御) × 乱数(1 ± 1/16)。四捨五入、最低 1
```

- 数値は `params.js` の `magic`（`intRate` 0.8、`mdefScale` 50）。技に `intRate` があればそちらを使う。乱数の幅は物理と同じ `damage.variance`
- 術防御は割合で減らす（術防御 50 で半分、150 で 1/4）。引き算ではないので、しゅび力の高い敵（ロックゴーレム・ボス）にもよく効く
- 術は会心にならず、ミスもない
- 例: メテオ（base 6）は Lv6（かしこさ約 20）で基礎 22。ロックゴーレム Lv6（術防御 7）に約 19

ノックバックはない。帰還中の敵（[enemies.md](enemies.md)）にはダメージが入らない（「無効」と出る）。
