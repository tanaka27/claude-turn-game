# ステータスとダメージ（物理・術）

ステータスの意味、技の種類（物理と術）、ダメージ計算。
数値は `params.js` の `damage` / `magic` / `derivedStats`、技の `kind` / `power` / `base` は `data/skills.js`（主人公の通常攻撃は `data/player.js`）と `data/enemies.js`。コードは `src/combat.js` の `rollDamage`。
技の範囲・予告は [combat.md](combat.md)。

## ステータス

主人公はドラクエ風（伸び方は行動と潜在。[growth.md](growth.md)）。敵も同じステータス（体力・意思・魔力・精神力・筋力・器用さ・すばやさ・知力・うんのよさ・会心倍率・HP再生・MP再生）を持ち、計算で決まるものは同じ式で出す。敵は装備のかわりに `gear` を足す（[enemies.md](enemies.md)）。

| ステータス | 意味 |
|---|---|
| 体力（con） | さいだいHP のもと。主人公は行動で伸びる（物理で受けるとよく伸びる。[growth.md](growth.md)）。Lv1 は 10 |
| 意思（will） | さいだいHP のもと。主人公は行動で伸びる（術で受けるとよく伸びる）。Lv1 は 10 |
| 魔力（mag） | さいだいMP のもと（1 で さいだいMP +1）と 術攻撃力 のもと（1 で +0.3）。主人公は術のスキルを使うと伸びる。Lv1 は 4 |
| 精神力（spi） | さいだいMP のもと（3 で さいだいMP +1。知力と合わせて ÷ 3）。主人公は行動で伸びる（MP を使うと伸びる）。Lv1 は 14 |
| 筋力（mus） | ちから・みのまもり のもと（どちらも効きが大きい）。主人公は物理で与えると伸び、物理で受けるとわずかに伸びる。Lv1 は 10 |
| 器用さ（dex） | ちから・みのまもり・命中 のもと。主人公は物理で与える・会心を出すと伸びる。Lv1 は 10 |
| すばやさ（agi） | 速度と回避を決める |
| 知力（int） | 術攻撃力（1 で +1。魔力より効く）・術防御・スキル加速と、さいだいMP（精神力と合わせて ÷ 3）を決める。Lv1 は 10。今は行動では伸びない（2026-11-25 までの名前は「かしこさ」） |
| うんのよさ（luk） | 会心率を決める。行動では上がらない |
| 会心倍率（critMult） / HP再生（hpRegen、1 ターンごと） / MP再生（mpRegen、1 ターンごと。Lv1 は 0.2） | 行動では上がらない |
| さいだいHP（maxHp） | 体力 + 意思 + 装備（Lv1 は 20） |
| さいだいMP（maxMp） | 魔力 + (知力 + 精神力) ÷ 3（切り捨て）+ 装備（Lv1 は 4 + (10 + 14) ÷ 3 = 12）。スキルを使うと MP が減る（消費 MP は [combat.md](combat.md)） |
| ちから（str） | 筋力 × 0.7 + 器用さ × 0.3 + 装備（Lv1 は 10）。こうげき力のもと |
| みのまもり（vit） | 筋力 × 0.32 + 器用さ × 0.08 + 装備（8:2。Lv1 は 3.2 + 0.8 = 4）。しゅび力のもと |
| こうげき力（atk） | ちから + 装備 |
| 術攻撃力（matk） | 知力 + 魔力 × 0.3 + 装備（Lv1 は 10 + 1.2 = 11.2）。術のダメージのもと |
| しゅび力（def） | みのまもり + 装備。物理の被ダメージを減らす |
| 術防御（mdef） | 知力 × 0.5 + 装備。術の被ダメージを減らす |
| 速度（speed） | 100 + (すばやさ − 20) × 2。行動 1 回 = 100 / 速度 ターン |
| スキル加速（skillHaste） | (知力 − 10) × 0.5。スキルの再使用 = 基本 × 100 / (100 + スキル加速) 行動 |
| 命中（hit） | 95% + 器用さ × 0.5% + 装備（Lv1 は 100%）。物理の攻撃の当たりやすさ |
| 回避（eva） | すばやさ × 0.25% + 装備（Lv1 は 5%）。物理の攻撃のかわしやすさ |
| 会心率（critRate） | うんのよさ × 0.5% |

計算で決まるものの式は `params.js` の `derivedStats`（主人公も敵も `deriveStats`、`src/units.js`）。
式の書き方は 2 つ: もとが 1 つなら `{ from: 'str', base, per, start }`（値 = start + (もと − base) × per）、もとが複数なら `{ from: { con: 1, will: 1 }, start, round }`（値 = start + Σ もと × 倍率。`round` なら Σ の部分を四捨五入、`floor` なら切り捨て）。どちらも装備でそのステータスに直接足す分が加わる。上から順に計算するので、計算で決まるステータスをもとにするとき（こうげき力 ← ちから ← 筋力・器用さ）は、もとのほうを先に書く。倍率の和が 1 の式（ちから）は小数の誤差が残らないよう 1e-9 で丸める。

## ステータスの計算の順番（主人公・敵・仲間で同じ）

戦うキャラはみな、自分のステータスをいつでも計算し直せるだけのもとを持つ（`statSource`）:

| キャラ | もとのステータス（強化・装備なし） | 装備の分 |
|---|---|---|
| 主人公 | Lv1 の値（`PLAYER.stats`）に行動で伸びた値を上書き（`base`） | 付けている装備（`equip`） |
| 敵 | 種類のステータスを敵レベルで補正したもの（`baseStats`。[enemies.md](enemies.md)） | `gear`（レベルで伸びた術防御を含む） |
| 仲間 | 種類の `stats`（`baseStats`） | 種類の `gear` |

`computeStats(u)` の順番:

1. もとのステータスから、装備なしで計算する（`deriveStats`。計算で決まるものも出す）= bare
2. 強化・弱体（`u.buffs`、`data/buffs.js`）の倍率を掛ける（`applyBuffs`）
3. 装備の分（装備ありで計算した値 − bare。ちから +3 ならこうげき力 +3 も入る）を足す。装備の分は倍率を受けない（例: ちから 13・武器 +4 で攻撃力アップ ×1.3 なら 13 × 1.3 + 4 = 20.9）
4. 上限（`derivedStats` の `max`）をかける

効果がなければ、敵・仲間は今までどおり「もとのステータス + gear を `deriveStats`」と同じ値になる（`tests/effects.test.js` が全部の敵でいくつかのレベルを確かめる）。
`refreshStats(u, keep)` で計算し直し、今の HP・MP を新しい最大に合わせる:

| keep | 合わせ方 | 使うところ |
|---|---|---|
| `clamp`（省略時） | 最大を超えた分だけ切る（切れても減った分は戻らない） | 強化・弱体をかける・切れる・消す |
| `shift` | 最大の増減ぶん今の値もずらす（HP は 1、MP は 0 が下限） | 装備の付け替え（`equipItem` / `unequipItem`）、行動でステータスが伸びたとき（`trainStat`） |
| `full` | 全回復 | レベルアップ、敵・仲間を作ったとき |

速度が変わると、次の行動から間隔（100 / 速度）が変わる（もう決まっている次の行動時刻はそのまま）。

## 技の種類（物理と術）

技は `kind` で物理（`'physical'`、省略時）と術（`'magic'`）に分かれる。

| 種類 | 計算に使う | 技 |
|---|---|---|
| 物理 | こうげき力 / しゅび力、技の `power` | 主人公: 斬撃・衝撃波・旋風斬。敵: 火を使うもの以外すべて |
| 術 | 術攻撃力 / 術防御、技の `base`（と `matkRate`） | 主人公: メテオ。敵: 火炎弾（サラマンダー）、胞子の雨（森の主）、火炎の息・隕石落とし（魔竜） |

敵のツールチップでは術の技に「（術）」と付く。

## 物理のダメージ計算（ドラクエ式）

```
当たる確率   = 攻撃側の命中 − 防御側の回避（75%〜100% に収める）。外れたら 0（「ミス」）
基礎ダメージ = (攻撃側のこうげき力 / 2 − 防御側のしゅび力 / 4) × 技の威力
基礎ダメージが 1 未満 → 0 か 1（半々。0 は「ミス」）
それ以外         → 基礎ダメージ × 乱数(1 ± 1/16)。四捨五入
会心のとき       → 防御を無視して こうげき力 / 2 × 会心倍率 × 技の威力 × 乱数(1 ± 1/16)。最低 1
```

- 数値は `params.js` の `damage`（`atkRate` 0.5、`defRate` 0.25、`minBase` 1、`variance` 1/16、`hitMin` 0.75、`hitMax` 1）。命中・回避の式は `derivedStats` の `hit` / `eva`
- 命中と会心は乱数 1 つで決める（`rollDamage`、`src/combat.js`）: 会心率より小さければ会心（**会心は必ず当たる**）、そのすぐ上の「1 − 当たる確率」の幅なら外れ、それより上ならふつうの当たり。外れの確率は会心率に関係なく「1 − 当たる確率」のまま
- 当たる確率は下限 75% なので、どれだけ すばやさ に差があっても 4 回に 1 回より多くは外れない。例（Lv1）: 主人公 → ウルフ（すばやさ 25）93.75%、→ ロックゴーレム（5）98.75%。ウルフ（器用さ 4.6）→ 主人公（すばやさ 20）92.3%、ロックゴーレム（7.1）→ 主人公 93.55%
- 外れたときも「ミス」と出し、受けた側の すばやさ が伸びる（`evade`）。基礎ダメージが 1 未満で 0 になったときと同じ扱い
- 引き算なので、しゅび力が相手のこうげき力の 2 倍に近づくとほとんど効かなくなる（レベルを上げると弱い敵の攻撃はミスばかりになる）。逆にこうげき力が足りないと、硬い敵（ロックゴーレム・ボス）にはミスが多くなる
- 会心はしゅび力を無視するので、硬い敵ほど会心がよく効く
- 「ミス」でも当たったことにはなる（弾は止まり、待機中の敵は追ってくる。クリックで歩いているのも止まる）

## 術のダメージ計算

```
基礎ダメージ = 技の固定値(base) + 攻撃側の術攻撃力 × matkRate
ダメージ     = 基礎ダメージ × 50 / (50 + 防御側の術防御) × 乱数(1 ± 1/16)。四捨五入、最低 1
```

- 術攻撃力 = 知力 + 魔力 × 0.3 + 装備（`derivedStats.matk`）。2026-11-25 までは知力をそのまま使っていた（Lv1 は 10 だったので、術のダメージは少し上がった）
- 数値は `params.js` の `magic`（`matkRate` 0.8、`mdefScale` 50）。技に `matkRate` があればそちらを使う。乱数の幅は物理と同じ `damage.variance`
- 術防御は割合で減らす（術防御 50 で半分、150 で 1/4）。引き算ではないので、しゅび力の高い敵（ロックゴーレム・ボス）にもよく効く
- 術は会心にならず、ミスもない（命中・回避は効かず、必ず当たる）
- 例: メテオ（base 6）は Lv1 の術攻撃力 11.2 で基礎 15、ロックゴーレム Lv7（術防御 8.81）に約 13。魔力が 24 まで伸びると術攻撃力 17.2 で基礎 19.8、同じゴーレムに約 17

ノックバックはない。帰還中の敵（[enemy-ai.md](enemy-ai.md)）にはダメージが入らない（「無効」と出る）。
