# 遊び方（操作・ゲームの流れ）

プレイヤーから見た操作とゲームの進み方。数値の詳細は各テーマのファイルにある。ターンと速度のしくみは [turn.md](turn.md)。

## 操作方法

| 操作 | 内容 |
|---|---|
| WASD / 矢印キー | 1 マス移動（1 行動） |
| Q / E / Z / C | 斜めに 1 マス移動（左上 / 右上 / 左下 / 右下）。テンキーの 1〜9 でも動ける |
| 敵のマスへ移動 | 通常攻撃（斬撃） |
| クリック | となりのマスなら移動・攻撃、自分のマスなら待つ、遠いマスならそこまで 1 歩ずつ歩く（敵に気づかれる・予告の範囲・攻撃を受けると止まる。右クリックでやめる） |
| Space / . | 1 回待つ（休息で HP・MP が回復する） |
| 1 / 2 / 3 / 4 | スキルを構える → マウスで狙ってクリック（同じキー・Enter でも使える）。範囲が白く出る。右クリック・Esc でやめる。2 は Lv3、3 は Lv6 で使えるようになる。使うと MP が減り、足りないと使えない |
| R / T | 回復薬（最大HP の 40% 回復）/ 上回復薬（80% 回復）を使う（1 行動） |
| I / 画面下の「道具」ボタン | 道具一覧を開く・閉じる（道具を使う、装備の付け替え・捨てる。戦闘中でも開ける） |
| F | となりの NPC に話しかける（NPC のマスへ移動しようとしても話しかける） |
| M / 右下の地図をクリック | 右下の地図を、今いるゾーンの地図と世界地図とで切り替える（行動にならない） |
| Esc / P | 一時停止（道具一覧・店・クエスト・キャラクターの画面を開いているときは閉じる） |
| C（一時停止中） | キャラクターの画面を開く・閉じる |
| マウスを敵に重ねる | 敵のレベル・名前・HP・ステータス・速度（自分の何倍か）・技・経験値・湧き場所を表示 |

キーを押しっぱなしにすると続けて行動する。行動しなければ時間は止まったまま（画面を開いている間も止まる）。

## ゲームの流れ

1. タイトル画面 →「はじめから」または「続きから」（セーブがあるときだけ出る。レベルと今いるゾーンを表示）
2. 始まりの町のかがり火から始まる。町は全体が安全地帯で、敵はいない。木の剣と布の服を装備し、30 G と回復薬 3 個を持っている
3. 光る床（門）に入ると隣のゾーンへ移る。門には行き先の名前と敵レベルの範囲が出る
   - 始まりの町 ⇄ 風の草原（Lv1〜5、ボス: 狼王 Lv6）⇄ 黒き森（Lv6〜8、ボス: 森の主 Lv9）⇄ 魔竜の遺跡（Lv9、ボス: 魔竜 Lv10）
   - 風の草原の東 ⇄ 風見の宿場（町）⇄ 赤岩の峡谷（Lv4〜8）⇄ 黒き森の東。黒き森の西 ⇄ 森の隠れ里（町）
4. 各ゾーンに敵の群れ（湧き場所）がいる。敵は普段その場をうろついていて、近づくと追ってくる。倒すと経験値が入り、決まったターン数のあとに同じ場所に湧き直す
5. 自分が 1 回行動するたびに、敵も速度に応じて動く。速い敵は自分が 1 回動く間に 2 回動くこともある。画面上の「行動順」で、これから誰がどの順に動くかが分かる
6. 強い技は予告（赤いマス）が出て、使った敵の次の番に当たる。「あと N」はそれまでに自分が動ける回数。範囲の外へ出れば当たらない
7. 敵（モンスター）は素材と、ときどき装備を落とす。落ちたマスに乗ると拾う。素材は町の商人に売るとお金になる。装備は道具一覧（I キーか画面下の「道具」ボタン）で付け替える
8. 町の店で回復薬と装備を買い、素材やいらない装備を売る。町は 3 つあり、店ごとに品ぞろえが違う（始まりの町はノーマルだけ、宿場はレアも、隠れ里は上回復薬とエピック。[items.md](items.md)）。始まりの町の衛兵隊長から討伐クエストを受ける（7 つが順に続き、最後は魔竜討伐）
9. 経験値がたまるとレベルアップ（さいだいHP・さいだいMP・ちから・みのまもり・すばやさ・かしこさが少しばらつきながら上がる。全回復）。すばやさが上がると速度が上がり、敵より多く動けるようになる
10. HP が 0 になると、最後に立ち寄った町のかがり火で復活する。所持金の 10% を失う（経験値とレベルは減らない）
11. 進行は自動で保存される。終わりはない。強くなって、より奥のゾーンやボスに挑む

画面下のメッセージ欄に、与えた・受けたダメージ、敵の構え、拾った物などが出る。
