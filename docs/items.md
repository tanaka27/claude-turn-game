# 装備・素材・お金・店

素材とお金、落とし物、装備の生成とレア度、回復薬、持ち物・店・キャラクターの画面。装備・回復薬・素材の定義は `data/items.js`（`ITEMS`）、お金・持ち物の数値は `params.js` の `economy`。ステータスの表示名は `data/stats.js`。コードは `src/items.js`（装備・落とし物）と `src/ui.js`（持ち物・店の画面）。

## お金・持ち物（`economy`）

| 項目 | 値 |
|---|---|
| 最初の所持金 | 30 G |
| お金の入り方 | 敵はお金を落とさない。敵が落とす素材を町の商人に売る。ほかにクエストの報酬、装備を売る |
| 持ち物に入る装備の数 | 24（いっぱいのときは装備を拾わない。素材は数の上限なしでいつも拾う） |
| 落とし物 | 敵が倒れたマスに落ちる。そのマスに乗ると拾う（ダッシュで通り過ぎても拾う）。300 ターンで消える（最後の 20 ターンは点滅）。ゾーンを移っても消える |
| 売値 | 価値の 25% |
| NPC に話しかけられる距離 | となりのマス（斜めを含む） |

## 素材（`materials`）

敵が倒れると、`data/enemies.js` の `drops` に従って素材を落とす（確率 `rate`、数 `count` は敵レベルで 1 レベルごとに +20%。[enemies.md](enemies.md)）。
素材は持ち物とは別に、種類ごとの数で持つ。店で 1 つずつ・種類ごと・全部まとめて売れる（売値はそのまま。装備のような `sellRate` はかからない）。

| 素材 | 売値 | 落とす敵 |
|---|---|---|
| 狼の毛皮 / 狼の牙 | 3 G / 8 G | ウルフ |
| ボアの角 / ボアの肉 | 5 G / 6 G | ホーンボア |
| 蜂の毒針 / 蜂蜜 | 4 G / 8 G | キラービー |
| 火トカゲの鱗 / 火炎袋 | 6 G / 12 G | サラマンダー |
| 岩の欠片 / 魔力の核 | 10 G / 30 G | ロックゴーレム |
| 狼王の毛皮 / 狼王の大牙 | 60 G / 40 G | 狼王 |
| 古木の枝 / 森の主の実 | 50 G / 100 G | 森の主 |
| 竜の鱗（×2） / 竜の心臓 | 40 G / 120 G | 魔竜 |

（1 体あたりの売値の期待値は、前に落としていたお金とほぼ同じにしてある）

## 装備（`items`）

部位は 武器（こうげき力）・防具（しゅび力とさいだいHP）・装飾品（基本性能なし。追加性能が 1 つ多い）の 3 つ。
装備レベルは、敵が落とした場合は敵のレベル、店で買う場合は自分のレベル。数値は `[Lv1 の値, 1 レベルごとの増加]` で決まる。

| 部位 | 基本性能 | 名前（2 レベルごとに変わる） |
|---|---|---|
| 武器 | こうげき力 1.2 + 0.6/Lv（整数に丸める） | 木の剣 → 銅の剣 → 鉄の剣 → 鋼の剣 → 騎士の剣 → 魔鋼の剣 → 竜骨の剣 → 聖剣 |
| 防具 | しゅび力 0.8 + 0.4/Lv、さいだいHP 1 + 0.6/Lv（整数に丸める） | 布の服 → 革の鎧 → 鋲打ちの鎧 → 鎖かたびら → 鋼の鎧 → 騎士の鎧 → 魔鋼の鎧 → 竜鱗の鎧 |
| 装飾品 | なし | 銅の指輪 → 銀の指輪 → 金の指輪 → … → 星の指輪 |

| レア度 | 色 | 敵が落とすとき | ボスが落とすとき | 基本性能 | 追加性能 | 価値 |
|---|---|---|---|---|---|---|
| ノーマル | 白 | 70% | 0% | ×1.0 | 0 | ×1 |
| レア | 青 | 25% | 60% | ×1.2 | 1 | ×2.5 |
| エピック | 紫 | 5% | 40% | ×1.45 | 2 | ×6 |

追加性能の候補（選ばれた値は ±20% で揺れる。基本性能と同じ種類は付かない）:
こうげき力 0.6 + 0.3/Lv、しゅび力 0.6 + 0.2/Lv、さいだいHP 1 + 0.6/Lv（この 3 つは整数に丸め、最低 1）、うんのよさ 4 + 0.4/Lv、会心倍率 0.08 + 0.01/Lv、
すばやさ 4 + 0.4/Lv（速度 +8 + 0.8/Lv）、かしこさ 10 + 2/Lv、HP再生 0.05 + 0.015/Lv（1 ターンごと）

価値（= 店の買値）: (10 + 8 × (Lv − 1)) × レア度の価値倍率

店の品ぞろえ: 部位ごとに、自分のレベルのノーマルとレアを 1 つずつ（計 6 個）と回復薬。自分のレベルが変わると、次に店を開いたときに入れ替わる

回復薬: 25 G。最大HP の 40% 回復、使うと 1 行動（再使用待ちはない）、最大 20 個まで持てる。最初は 3 個

## 仕組み: 装備・落とし物・店

- `makeItem(部位, レベル, レア度, ボスか)` が装備を作る。装備は `{ id, slot, name, rarity, level, stats }` の形で、そのまま保存する
- 敵が倒れると `dropLoot` が素材（`kind: 'material'`）と装備（`kind: 'item'`）を `loots` に落とす。落とし物はマス（`tx`, `ty`）と、重ならないように少しずらして描く位置を持つ。主人公がマスに入ると `pickUpAt` が拾い、`updateLoots` が時間で消す。拾った素材は `player.materials`（`{ 素材のid: 数 }`）に足す
- 持ち物・店・キャラクターの画面は HTML（`index.html` の `#menu`）。`openMenu('inv' | 'shop' | 'char')` で開き、`renderMenu` が中身を作る。ボタンの処理は `#menu` のクリックをまとめて受けて振り分ける
  - 装備を選ぶと、同じ部位の装備中のものとの差を緑（上がる）・赤（下がる）で表示する
  - 何も選んでいないときは「つよさ」（`strengthHtml`）を出す: 全ステータスと、装備で上がっている分（装備がないときとの差）
  - キャラクターの画面（`'char'`）は一時停止画面の「キャラクター」ボタンか、一時停止中の C キーで開く。持ち物の画面と同じく装備の付け替え・外す・捨てるができ、左上に名前・レベル・HP・経験値（次のレベルまで）・撃破数・今いるゾーン（`profileHtml`）、装備を選んでいるときも詳細の下に「つよさ」を出す。閉じると（Esc / C / 閉じる）一時停止画面に戻る（`closeMenu` が `showPause` を呼ぶ）
- NPC は `world.js` の `npcs`（NPC のマスは通れない）。`nearNpc` がとなりの NPC を探し、F キーの `interact`、または NPC のマスへの移動（`tryMove`）で `talkTo` が役割（`shop` / `quest`）に応じた画面を開く
- 持ち物の列の下に素材の一覧を出す（`renderMaterials`）。店では各素材に「1つ売る」「全部」、見出しに「全部売る」のボタンが付く（`sellMaterial`）
- 店の品ぞろえは `refreshShop` が自分のレベルが変わったときだけ作り直す（セーブはしない）
