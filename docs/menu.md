# 道具一覧・店・キャラクターの画面

HTML で作る画面（`index.html` の `#menu`）のしくみ。コードは `src/ui.js`。装備・回復薬・素材・店の中身（数値）は [items.md](items.md)。クエストの画面は [progression.md](progression.md)。

## 開き方

| 画面 | `menu.mode` | 開き方 | 閉じ方 |
|---|---|---|---|
| 道具一覧（自分が持っている物） | `'inv'` | I キー、HUD のスキル欄の右端の「道具」ボタン（クリック。[ui.md](ui.md)） | Esc / I / 閉じる |
| 商人（回復薬を買う・素材を売る） | `'shop'` | 商人の NPC に話しかける（F、または NPC のマスへ移動） | Esc / F / 閉じる |
| 鍛冶屋（装備を買う・売る） | `'smith'` | 鍛冶屋の NPC に話しかける（F、または NPC のマスへ移動） | Esc / F / 閉じる |
| 会話（話すだけの NPC） | `'talk'` | 話すだけの NPC に話しかける。画面の下に出る（[buildings.md](buildings.md)） | F / Enter / スペース / クリックで次へ（最後で閉じる）、Esc / 閉じる |
| キャラクター | `'char'` | Tab キー、HUD の左上の仲間の欄（クリック）、一時停止画面の「キャラクター」ボタン、一時停止中の C キー | Esc / Tab / C / 閉じる（一時停止から開いたときは一時停止画面に戻る） |

画面を開いている間は `game.state = 'menu'` で、時間（ターン）は止まる。開く・装備を付け替えるのは行動にならない（戦闘中でもいつでも付け替えられる）。道具を使うのは 1 行動。

## 仕組み

- 道具一覧（自分が持っている物の一覧）・店・キャラクターの画面は HTML（`index.html` の `#menu`）。`openMenu('inv' | 'shop' | 'smith' | 'char', 店のキー)` で開き（商人・鍛冶屋のときは `menu.shop` に店のキー。`shopDef` が `ITEMS.shops` か `ITEMS.smiths` から引く）、`renderMenu` が中身を作る。ボタンの処理は `#menu` のクリックをまとめて受けて振り分ける
- 道具一覧（`'inv'`）は I キーか HUD の「道具」ボタンで開く。中央の列の上から 道具（使う物）・装備品（持っている装備）・素材
- 道具は `toolEntries` が `{ id, name, rarity, count, max, key, desc, usable, use }` の形で並べる（今は回復薬だけ）。道具一覧では「使う」で画面を閉じて `act(use)` で使う（1 行動）。店・キャラクターの画面では数だけ出す。飛び道具など使う物を増やすときは `toolEntries` に足す
- 道具・装備・素材は、名前と左のふちをレア度の色にし、説明の先頭にレア度の名前を出す（素材は名前の前に素材の色のひし形も出す）
- 装備の詳細（`detailHtml`）は「基本性能」（部位で決まる。`IT.slots[部位].base` のキー）と「追加性能（数）」（ランダムに付いたもの）の 2 つの欄に分けて出す。中身がない欄は「なし」
- 装備を選ぶと、同じ部位の装備中のものとの差を緑（上がる）・赤（下がる）で表示する。装備中のものにだけある追加性能は、追加性能の欄の最後に名前を薄くして「-」と差（赤）で出す
- 何も選んでいないときは「つよさ」（`strengthHtml`）を出す: 全ステータスの最終的な値（強化と装備を入れたもの）と、その後ろの（ ）に装備で上がっている分（`statParts` の `equip`。例: こうげき力 21（+4））。強化がかかっているステータスは値をオレンジの太字にする
- キャラクターの画面（`'char'`）は Tab キーか HUD の左上の仲間の欄のクリックで開く（一時停止画面の「キャラクター」ボタン・一時停止中の C キーでも）。フィールドの HUD には顔・名前・レベル・HP・MP しか出さないので、それ以外はこの画面で見る。道具一覧と同じく装備の付け替え・外す・捨てるができ、左上に顔の絵・名前・レベル・HP・MP（ゲージつき）・経験値（次のレベルまで）・撃破数・状態（安全地帯／休息中／戦闘中）・ターン数・今いるゾーンと敵レベル・受けているクエストの進み具合（報告できるものは緑）（`profileHtml`）、見出しに所持金、右に「つよさ」（全ステータス）を出す。装備を選んでいるときも詳細の下に「つよさ」を出す。一時停止から開いたときは、閉じると一時停止画面に戻る（`closeMenu` が `showPause` を呼ぶ）
- 装備品の列の下に素材の一覧を出す（`renderMaterials`）。商人では各素材に「1つ売る」「全部」、見出しに「全部売る」のボタンが付く（`sellMaterial`）
- 商人（`'shop'`）は左の「商品」に回復薬を並べる。鍛冶屋（`'smith'`）は「商品」に装備を並べ（選ぶと「買う」）、装備品の列の装備を選ぶと「捨てる」の代わりに「売る」が出る
