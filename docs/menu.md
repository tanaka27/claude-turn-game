# 道具一覧・店・キャラクターの画面

HTML で作る画面（`index.html` の `#menu`）のしくみ。コードは `src/ui.js`。装備・回復薬・素材・店の中身（数値）は [items.md](items.md)。クエストの画面は [progression.md](progression.md)。

## 開き方

| 画面 | `menu.mode` | 開き方 | 閉じ方 |
|---|---|---|---|
| 道具一覧（自分が持っている物） | `'inv'` | I キー、HUD のスキル欄の右端の「道具」ボタン（クリック。[ui.md](ui.md)） | Esc / I / 閉じる |
| 店 | `'shop'` | 店の NPC に話しかける（F、または NPC のマスへ移動） | Esc / F / 閉じる |
| キャラクター | `'char'` | 一時停止画面の「キャラクター」ボタン、一時停止中の C キー | Esc / C / 閉じる（一時停止画面に戻る） |

画面を開いている間は `game.state = 'menu'` で、時間（ターン）は止まる。開く・装備を付け替えるのは行動にならない（戦闘中でもいつでも付け替えられる）。道具を使うのは 1 行動。

## 仕組み

- 道具一覧（自分が持っている物の一覧）・店・キャラクターの画面は HTML（`index.html` の `#menu`）。`openMenu('inv' | 'shop' | 'char', 店のキー)` で開き（店のときは `menu.shop` に店のキー）、`renderMenu` が中身を作る。ボタンの処理は `#menu` のクリックをまとめて受けて振り分ける
- 道具一覧（`'inv'`）は I キーか HUD の「道具」ボタンで開く。中央の列の上から 道具（使う物）・装備品（持っている装備）・素材
- 道具は `toolEntries` が `{ id, name, rarity, count, max, key, desc, usable, use }` の形で並べる（今は回復薬だけ）。道具一覧では「使う」で画面を閉じて `act(use)` で使う（1 行動）。店・キャラクターの画面では数だけ出す。飛び道具など使う物を増やすときは `toolEntries` に足す
- 道具・装備・素材は、名前と左のふちをレア度の色にし、説明の先頭にレア度の名前を出す（素材は名前の前に素材の色のひし形も出す）
- 装備を選ぶと、同じ部位の装備中のものとの差を緑（上がる）・赤（下がる）で表示する
- 何も選んでいないときは「つよさ」（`strengthHtml`）を出す: 全ステータスと、装備で上がっている分（装備がないときとの差）
- キャラクターの画面（`'char'`）は一時停止画面の「キャラクター」ボタンか、一時停止中の C キーで開く。道具一覧と同じく装備の付け替え・外す・捨てるができ、左上に名前・レベル・HP・経験値（次のレベルまで）・撃破数・今いるゾーン（`profileHtml`）、装備を選んでいるときも詳細の下に「つよさ」を出す。閉じると（Esc / C / 閉じる）一時停止画面に戻る（`closeMenu` が `showPause` を呼ぶ）
- 装備品の列の下に素材の一覧を出す（`renderMaterials`）。店では各素材に「1つ売る」「全部」、見出しに「全部売る」のボタンが付く（`sellMaterial`）
