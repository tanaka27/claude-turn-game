# 道具一覧・店・キャラクターの画面

HTML で作る画面（`index.html` の `#menu`）のしくみ。コードは `src/ui.js`。画面の開き方・閉じ方・キー・ボタンの振り分け（画面の登録表 `SCREENS`）と NPC の役目（`NPC_ROLES`）、施設の足し方は [screens.md](screens.md)。装備・素材・店の中身（数値）は [items.md](items.md)、道具（回復薬など）の定義と使う道は [consumables.md](consumables.md)。クエストの画面は [quests.md](quests.md)。

## 開き方

| 画面 | `menuState.mode` | 開き方 | 閉じ方 |
|---|---|---|---|
| 道具一覧（自分が持っている物） | `'inv'` | I キー、HUD のスキル欄の右端の「道具」ボタン（クリック。[ui.md](ui.md)） | Esc / I / 閉じる |
| 商人（道具を買う・素材を売る） | `'shop'` | 商人の NPC に話しかける（F、または NPC のマスへ移動） | Esc / F / 閉じる |
| 鍛冶屋（装備を買う・売る） | `'smith'` | 鍛冶屋の NPC に話しかける（F、または NPC のマスへ移動） | Esc / F / 閉じる |
| 会話（話すだけの NPC） | `'talk'` | 話すだけの NPC に話しかける。画面の下に出る（[buildings.md](buildings.md)） | F / Enter / スペース / クリックで次へ（最後で閉じる）、Esc / 閉じる |
| キャラクター | `'char'` | Tab キー、HUD の左上の仲間の欄（クリック）、一時停止画面の「キャラクター」ボタン、一時停止中の C キー | Esc / Tab / C / 閉じる（一時停止から開いたときは一時停止画面に戻る）。タブは クリック / ← → / 1〜4 で切り替え |

画面を開いている間は `game.state = 'menu'` で、時間（ターン）は止まる。開く・装備を付け替えるのは行動にならない（戦闘中でもいつでも付け替えられる）。道具を使うのは 1 行動。

## 仕組み

- 道具一覧（自分が持っている物の一覧）・店・キャラクターの画面は HTML（`index.html` の `#menu`）。どれも画面の登録表 `SCREENS` の 1 つで（`menuScreen` で作る。[screens.md](screens.md)）、`openScreen('inv' | 'shop' | 'smith' | 'char', 店のキー)` で開き（商人・鍛冶屋のときは `menuState.shop` に店のキー。`shopDef` が開いている画面の `defs()`（`ITEMS.shops` / `ITEMS.smiths`）から引く）、`renderMenu` が中身を作る。画面ごとの違い（見出し・「商品」の欄・素材を売るボタン・道具の「使う」・「捨てる」か「売る」か）は画面の定義に書く。ボタンは `#menu` のクリックを 1 か所で受け、開いている画面の `actions`（共通のものは `MENU_ACTIONS`）から引いて呼ぶ
- 道具一覧（`'inv'`）は I キーか HUD の「道具」ボタンで開く。中央の列の上から 道具（使う物）・装備品（持っている装備）・素材
- **道具一覧とキャラクターの画面では、アイテム（装備・道具・素材）をクリックすると詳細がポップアップで開く**（`menuState.pop`、`openPop` / `renderPop`。`usesPop()` が true の画面）。メニューの上に暗い幕をかけ、中央に詳細の箱（ふちはレア度の色）を出す。「閉じる」ボタン・幕のクリック・Esc（ポップアップだけ閉じる）で閉じる（`closePop`）。右の欄はいつも「つよさ」で、ポップアップで付け替えるとすぐ変わる
  - 装備（`{ kind: 'gear' }`。どれかは `menuState.sel`）: 下の装備の詳細（`detailHtml`）と「装備する」「捨てる」「外す」。付け替えたあともポップアップは開いたまま（装備した物は「外す」の表示に変わる）。捨てると閉じる
  - 道具（`{ kind: 'tool', id }`、`toolPopHtml`）: 説明・持っている数・使うキー。道具一覧で一時停止していなければ「使う」（使えないときは理由（`toolEntries` の `reason`）を出す）
  - 素材（`{ kind: 'mat', id }`、`matPopHtml`）: 持っている数・売値（全部での値段）・落とす魔物（`data/enemies.js` の `drops` から引く）
  - 商人・鍛冶屋の画面では今までどおり、選んだ装備の詳細を右の欄に出す（ポップアップは使わない）
- 道具は `toolEntries` が `data/items.js` の `consumables` から `{ id, name, rarity, count, max, key, desc, usable, reason, use }` の形で並べる。`usable` と `reason`（使えない理由）は使うときと同じ判定 `consumableBlock`、`use` は `useConsumable(主人公, id)`（[consumables.md](consumables.md)）。道具一覧では「使う」で画面を閉じて `doPlayerAction(use)` で使う（1 行動）。店・キャラクターの画面では数だけ出す。道具を増やすときは `data/items.js` の `consumables` に足す
- 道具・装備・素材は、名前と左のふちをレア度の色にし、説明の先頭にレア度の名前を出す（素材は名前の前に素材の色のひし形も出す）
- 装備の詳細（`detailHtml`）は「基本性能」（部位で決まる。`ITEMS.slots[部位].base` のキー）と「追加性能（数）」（ランダムに付いたもの）の 2 つの欄に分けて出す。中身がない欄は「なし」
- 装備を選ぶと、同じ部位の装備中のものとの差を緑（上がる）・赤（下がる）で表示する。装備中のものにだけある追加性能は、追加性能の欄の最後に名前を薄くして「-」と差（赤）で出す
- 右の欄の「つよさ」（`strengthHtml`。店では何も選んでいないとき）: 全ステータスの最終的な値（強化と装備を入れたもの）と、その後ろの（ ）に装備で上がっている分（`statParts` の `equip`。例: こうげき力 21（+4））。強化・弱体がかかっているステータスは値をオレンジの太字にする（上がっても下がっても同じ色）。見出しで 2 つに分ける: 「基礎能力値」（行動で伸びるもの。`params.js` の `progression.growth.stats` にあるもの: 体力・意思・魔力・精神力・筋力・器用さ・すばやさ・知力）と、「ステータス」（それ以外。基礎能力値から計算で決まるもの（`derivedStats`）と、装備でだけ変わるもの（うんのよさ・会心倍率・再生））。見出しの文は `data/text.js` の `menu.baseStats` / `menu.derivedStats`、並びはどちらも `data/stats.js` の順
- キャラクターの画面（`'char'`）は Tab キーなどで開く。中身はタブ（ステータス・装備・持ち物・クエスト）に分けてある。詳しくは [character.md](character.md)
- 装備品の列の下に素材の一覧を出す（`renderMaterials`）。商人では各素材に「1つ売る」「全部」、見出しに「全部売る」のボタンが付く（`sellMaterial`）
- 商人（`'shop'`）は左の「商品」にその店の道具（`shops[*].consumables`）を並べ、「買う」（`data-act="buyItem"`）で 1 つ買う（お金が足りない・持てる数までいっぱいなら押せない）。鍛冶屋（`'smith'`）は「商品」に装備を並べ（選ぶと「買う」）、装備品の列の装備を選ぶと「捨てる」の代わりに「売る」が出る
- 選んだ装備に出るボタン（`detailHtml`）: 持ち物の装備は「装備する」と「捨てる」（鍛冶屋では「売る」）、装備中のものは「外す」、鍛冶屋の商品は「買う」。押したときもこの組み合わせのときだけ効き、ほかは何もしない（お金・持ち物・装備は変わらない）。たとえば、買った直後の 2 回目の「買う」（選んでいるのは持ち物の側に移った装備）、品ぞろえにもうない装備の「買う」、商品を選んでいるときの「装備する」「売る」「捨てる」、鍛冶屋での持ち物の「捨てる」は効かない（[screens.md](screens.md) の `actions`）
