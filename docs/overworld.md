# ワールドマップ（町・ダンジョンの入口・地方）

大きなワールドマップが 1 つあり、その上に町・ダンジョンの入口が並ぶ。入口のマスを踏むとその町・ダンジョンのゾーンに入り、町・ダンジョンの外へ出る門を踏むとワールドマップの入口の前に戻る。
配置は `world.js` の `WORLD.zones.world`（どのゾーンがワールドマップかは `WORLD.overworld`）。読み込みは `src/map.js`、世界地図は `src/hud.js`（[worldmap.md](worldmap.md)）。町・ダンジョンの中のゾーンと、マス目・門・湧き場所の仕組みは [world.md](world.md)。

## 地図の書き方（grid で描くゾーン）

ワールドマップは、ほかのゾーンのように障害物を四角で並べるのではなく、**1 文字 = 1 マスの文字列の配列（`grid`）** で描く（144 × 96 マス）。

| 文字 | 意味（`WORLD.legend`） | 種類 |
|---|---|---|
| `.` | 草地 `grass` | 地面（通れる） |
| `:` | 荒れ地 `sand` | 地面 |
| `;` | 森の下草 `moss` | 地面 |
| `=` | 道 `road` | 地面 |
| `-` | 雪原 `snow` | 地面 |
| `~` | 海・湖（地形 `water`） | 移動だけを遮る |
| `^` | 山（地形 `mountain`） | 移動も攻撃も遮る |
| `*` | 木（地形 `tree`） | 移動も攻撃も遮る |
| `#` | 岩（地形 `wall`） | 移動も攻撃も遮る |
| 英大文字 | 入口（`places` のキー） | 通れる（踏むと入る） |

- 地面の種類は `WORLD.grounds`（`color`: 描く色、`minimap`: ミニマップ・世界地図の色）。地形は `WORLD.terrain`
- 起動時に一度だけ `expandGridZones`（`src/map.js`）が `grid` をふつうのゾーンと同じ形（`w`・`h`・`obstacles`・`gates`、px）と地面の塗り分け `grounds` に直す。同じ文字が並ぶところは 1 つの四角にまとめる（`gridRects`）。`perTile: true` の地形（木・山）は 1 マスずつ描く
- 外周の壁は付けない（`edgeWalls: false`）。外周は通れない文字で囲む（データの確認で調べる）
- 入口のマスの地面はゾーンの `ground`（草地）。入口から出てきたときは、入口の下（通れなければ上・右・左）のマスに立つ
- 湧き場所・地方の位置は、マスの列・行から `WORLD_CELL.pos(列, 行)`（マスの中心の px）/ `WORLD_CELL.rect(列, 行, 幅, 高さ)` で書く
- 地図を大きく描き直したいときは文字列をそのまま書き換えてよい（行の長さはそろえる）

## 全体の形

```
 ~~~~~~~ 魔竜の山（まん中の盆地に 魔竜の遺跡 E）~~~~~~~ ~海峡~ 霜降りの高原（雪原・山）
        森の主の祠 G      |                                       霜の村 I
 森の隠れ里 D ── 黒き森 ──┼── 赤岩の峡谷 ── 岩根の村 C ══(東の橋)══╝   ║
                  |                  |                     （峠）  ║
              狼の洞穴 F             |                   ^^^^^^^^^^^^^^^^^^
 始まりの町 A ═══ 風の草原（街道）═══ 風見の宿場 B ═════(東の橋)═══ 潮風の港 H（潮騒の海岸）
 ~~~~~~~~~~~~~~ 海 ~~~ ║(西の橋) ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ ║(南の橋) ~~~~~
 迷いの湿地 ═══════════╬══ 砂の都 J ═══════ 灼熱の砂丘（オアシス）════╝
 ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ 海 ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
```

- もとの 96 × 64 マスの地図は左上（列 0〜95、行 0〜63）にそのまま残してあり、東（列 96〜）と南（行 64〜）に陸を足した。もとの場所の座標は変わらない（前のセーブの位置もそのまま使える）
- 東と南の陸は海峡で分かれていて、道の橋（`=`）でつながる。東の橋は 2 本（岩根の村 → 霜降りの高原、風見の宿場 → 潮騒の海岸）、南の橋は 2 本（草原の南 → 砂丘、潮風の港の南 → 砂丘）

- 町・ダンジョンからワールドマップへ出る門の名前は「→ ルーメ大陸へ出る」（`world.gateOutLabel`）

## 地方（`regions`）

ワールドマップを 8 つの地方に分ける（重なったところは先に書いた地方。敵レベルの幅も、湧き場所ごとにどの地方かを同じ決まりで決めて数える）。主人公が別の地方に入ると、画面のまん中に地方の名前とその地方の敵レベル（地方の中の湧き場所だけで数える）を出す（`checkRegion`。門を調べるときに一緒に呼ぶ）。ワールドマップに出たときは、ゾーン名の下に今いる地方を出す。

## データの確認

- `WORLD.overworld` のゾーンがあり、`grid` で描いているか
- `legend` の値が `terrain` か `grounds` のどちらか一方にだけあるか。英大文字を `legend` に使っていないか
- `grid` の行の長さがそろっているか、文字が `legend` か `places` にあるか、入口の文字がちょうど 1 つずつあるか、外周が通れないか
- はじめの町の入口から、ワールドマップの上を歩いて全部の入口と湧き場所に行けるか

## 足し方

- 町・ダンジョンを足す: `zones` にゾーンを足し、外へ出る門を `to: 'world', toGate: '<入口の id>'` にする。ワールドマップの `grid` の置きたいマスに新しい英大文字を書き、`places` にその文字を足す
- 地方を足す: `regions` に 1 行足す（先に書いたほうが優先）
