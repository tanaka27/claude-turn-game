# 成長（レベル・クエスト・スキル解放）

経験値とレベル、ステータスの成長、討伐クエスト、スキル解放。数値は `params.js` の `progression`、クエストは `data/quests.js`（`QUESTS`）、スキル解放は `data/player.js` の技の `unlockLevel`。コードは `src/units.js`（成長）と `src/quests.js`。

## 成長（`progression`）

| 項目 | 値 |
|---|---|
| 次のレベルまでの経験値 | 60 × 現在レベル ^ 1.5（Lv1→2 は 60、Lv5→6 は 671） |
| 最大レベル | 30 |
| レベルアップ | さいだいHP・さいだいMP・ちから・みのまもり・すばやさ・かしこさ が成長曲線に沿って上がる（下の表）。HP・MP は全回復 |
| 倒れたとき | 所持金の 10% を失う（`deathGoldLoss`）。経験値は減らない（`deathExpLoss` = 0） |
| 休息 | 最後に攻撃を受けてから 8 ターンたつと、HP再生に加えて 1 ターンごとに 最大HP の 3%、MP再生に加えて 最大MP の 2%（`restMpRegenRate`）回復（待つ・歩くどちらでも） |
| 倒れて復活したとき | HP・MP とも満タン |

## ステータスの成長（`progression.growth`）

ドラクエ風。レベルごとの目安の値（成長曲線）に近づくように、毎回ばらつきながら上がる。
うんのよさ・会心倍率・HP再生・MP再生はレベルアップでは上がらない（装備でだけ変わる）。
レベルアップで選んで上げる強化（ローグライク風）はない（2026-11-03 に廃止）。

```
上がる量 = round(目安(新しいレベル) − 今の値 + 乱数(±spread))、0 未満は 0
```

目安は Lv1 の値（`data/player.js`）＋ `gain` の点を直線でつないだ増加量。
1 レベルあたり さいだいHP は約 +3、ちから は約 +1、みのまもり は 0〜1 ずつ上がる。

| ステータス | Lv1 | Lv10 | Lv20 | Lv30 | spread |
|---|---|---|---|---|---|
| さいだいHP | 20 | 45 | 75 | 105 | 1.5 |
| さいだいMP | 12 | 26 | 44 | 62 | 1 |
| ちから | 10 | 19 | 29 | 39 | 0.6 |
| みのまもり | 4 | 8 | 12 | 16 | 0.4 |
| すばやさ | 20 | 32 | 46 | 60 | 0.8 |
| かしこさ | 10 | 28 | 48 | 70 | 1.5 |

すばやさ 1 で速度 +2（[turn.md](turn.md)）。速度は Lv1 で 100、Lv10 で約 124、Lv20 で約 152、Lv30 で約 180。かしこさは Lv30 でスキル加速 +30、術防御 35。かしこさ 1 につき術のダメージ（基礎）+0.8（[damage.md](damage.md)）。

レベルアップの表示は「LEVEL UP! Lv 7」の下に上がった量を並べる（例: さいだいHP +3　ちから +1 …）。新しいスキルがあれば次の行に出す。

## クエスト（`quests`）

始まりの町の衛兵隊長（物語の討伐。順に続く）と、冒険者ギルドの受付（[buildings.md](buildings.md)。くり返し受けられる依頼が中心）から受ける。前のクエスト（`requires`）を報告し、レベルが足りていると受けられる。
報酬の装備のレベルは、報告したときの自分のレベル。

## 仕組み: 成長

- 敵を倒すと `gainExp` で経験値が入り、必要量を超えるたびに `levelUp`
- 成長した値は `player.base`（`{ maxHp, maxMp, str, vit, agi, int }`）に持つ（ばらつきがあるのでレベルからは計算できない）。`levelUp` が `growthTarget`（目安）に向けて足す。はじめからのときと、`base` のない前のセーブは `growthBase`（そのレベルの目安どおり）
- ステータスは `computeStats` で毎回計算する: Lv1 の値（成長するものは `base`）→ `derivedStats` で こうげき力などを計算 → 強化（`player.buffs`）の倍率を掛ける → 装備（`player.equip`）で上がる分を足す。装備で上がる分は `statParts` が「装備ありで計算した値 − 装備なしで計算した値」で出す（ちから +3 の装備ならこうげき力にも +3 が入る）。上限（`max`）は最後にかける
- プレイヤーが倒れると、その場で所持金（と `deathExpLoss` 分の経験値）を減らして保存し、1.4 秒後（実時間）に `respawnPlayer` で最後に立ち寄った町（`player.home`。[world.md](world.md)）のかがり火へ戻る

## 仕組み: クエストとスキル解放

- クエストの状態は `player.quests[id] = { state, count }`。`questStatus` が `locked`（前のクエストがまだ）/ `lowLevel` / `available` / `active` / `ready`（報告できる）/ `claimed`（報告済み）を返す
- 敵が倒れると `questKill` が受けているクエストの数を進め、達成したら `ready` にして画面に知らせる
- くり返しのクエスト（`repeatable`）は、報告すると `player.quests` から記録を消すので、また `available` になる。ほかのクエストの `requires` には使えない（データの確認で調べる）
- NPC の頭上の印: 報告できるクエストがあれば「?」、くり返しでないクエストを受けられれば「!」（くり返しの依頼だけなら印は出さない。`npcMark`）
- クエストの画面は HTML（`index.html` の `#quest`）。`openQuest` で開く。左が依頼の一覧（`questEntries`。報告できる → 受けている → 受けられる → レベル不足 → 報告済みの順。前のクエストがまだのものは出さない）、右が選んでいる依頼の内容（説明・倒す敵と数・場所・報酬）と「受ける」「報告する」ボタン。一覧はクリックか ↑↓ で選び（`moveQuestSel`）、Enter かボタンで受ける・報告する（`questAction`）。`renderQuest` が中身を作る
- 報告すると `claimQuest` が報酬を渡す（装備の報酬は持ち物がいっぱいだと受け取れない）
- スキルは `unlockLevel` 未満だと押しても発動せず、案内を出す。`levelUp` で新しく使えるようになったスキルを画面に出す
