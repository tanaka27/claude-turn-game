# セーブとサーバー

いつ保存するか（自動と手動）、保存先（ブラウザとサーバー）、保存できないときの知らせ、読み込み。コードは `src/save.js`。
サーバー（`server.py`）の API と、古いタブで新しい進行を上書きしないしくみは [server.md](server.md)。
保存する項目を増やす・形を変えるときは、[save-versions.md](save-versions.md) の「形を変えるとき（版を足す）」の手順で版を 1 つ上げる。

## いつ保存するか（`params.js` の `save`）

- 30 秒ごと（`interval`。実時間）、門を通ったとき、レベルアップ、持ち物・店・クエストの画面を閉じたとき、クエストを受けた・報告したとき、倒れたとき、復活したとき、ページを閉じるとき
- **手動のセーブ**: 一時停止画面の「セーブ（S）」ボタン、一時停止中の S キー（`manualSave`、`src/ui.js`）。自動のセーブと同じ `saveGame` で保存し、「保存しています…」のあと結果を `#saveResult` に出す（`saveResultText`: サーバーとブラウザ / サーバーだけ / ブラウザだけ / ブラウザだけでサーバーは失敗（理由つき）/ どこにも保存できなかった）。一時停止を開き直すと結果は消える
- どの保存でも 30 秒の時計は数え直す（直前に保存していれば、次の自動のセーブは 30 秒後）
- `saveGame(unloading)` は Promise を返す。終わると `{ local: ブラウザに書けたか, server: 'ok' | 'error' | 'conflict' | 'none' }`（タイトル・保存をやめたタブでは保存せず `skipped: true`）
- サーバーへ問い合わせるときは、返事の本文を読み終わるまでで 5 秒まで待つ（`serverTimeout`。返事の頭だけ来て本文が届かないときも時間で打ち切る）。時間内に返事がない・つながらないとき（`unreachable`）は、ブラウザだけに保存しながら、次に保存するときにもう一度確かめ、つながったら今のセーブを送る（`retryServer`）。404 など「サーバーではない」返事のときは確かめ直さない

## 保存先

| 起動のしかた | 保存先 |
|---|---|
| `start.bat` または `python server.py`（おすすめ） | サーバーの `saves/save.json` と、ブラウザの `localStorage`（キー `zankai-turn-save`）の両方 |
| `python -m http.server` や `index.html` を直接開く | ブラウザの `localStorage` だけ |

- 起動時（`initSave`）に両方を読み、それぞれ今の形に直してから `savedAt` が新しいほうを使う（ブラウザが v1・サーバーが v2 のように版が違っても比べられる）。ブラウザにしかないセーブ（またはブラウザのほうが新しいセーブ）は、そのとき（今の形に直したものを）サーバーにも送る。サーバーに使えないセーブがあるときは送らない
- サーバーへの送信は 1 つずつ。送っている間に次のセーブが来たら、終わってから一番新しいものだけを送る。ページを閉じるときは待たずに送る（`keepalive`）
- サーバーに保存できなかったときはブラウザには保存し、一時停止画面にその旨を出す。保存先の説明はタイトルと一時停止画面に出る（`saveWhereText`）
- **ブラウザに書けないとき**（容量がいっぱい・ブラウザの設定で `localStorage` が使えない）: `writeLocalSave` が false を返し `saveStore.localOk = false`。保存先の説明は、サーバーに書けていれば「サーバーには保存、ブラウザには保存できない」（`save.serverOnly`）、サーバーにも書けなければ「進行を保存できていません」（`save.nowhere`）にする（「自動で保存されています」とは出さない）。どこにも保存できなくなったときはメッセージ欄にも 1 回出す（`save.failedLog`。保存できるようになったらまた出せる）
- ほかのタブで遊び始めたとき・サーバーにほかのタブの新しいセーブがあったときは、このタブでは保存をやめる（[server.md](server.md) の「古いタブで上書きしない」）
- キーは、もとのリアルタイム版（斬界アリーナ、`zankai-arena-save`）とは別。同じブラウザで両方遊んでも混ざらない（ポートも 8766 と 8765 で別）

## 仕組み: 読み込みと開始

- タイトル画面は `initSave` が終わるまで「はじめから」を押せない。終わると `refreshTitle` が「続きから（Lv・ゾーン）」と、使えないセーブの説明（`saveProblemText`）と保存先を出す
- 「続きから」「はじめから」を押すと、まず `claimSave` でほかのタブに保存をやめさせ、セーブを読み直してから（`initSave` をもう一度）タイトルを出し直し、読み直した一番新しいセーブで始める（[server.md](server.md)）
- `startGame(save)`: 主人公を作り直し、save があれば `applySave` で中身を戻して保存した場所から始める。HP は数（`Number.isFinite`）で 0 より大きければその値（最大まで。端数もそのまま）、それ以外（0 以下・`null`・文字列など）は満タン（生きている主人公を HP 0 で戻すことはない。倒れている間のセーブは `hp: null`）。MP は数なら 0〜最大に収めた値（0 もそのまま）、数でなければ満タン。「はじめから」はセーブ（使えないものも）があると確認してから上書きする
- デバッグ用に `window.__game.saveStore` で保存先の状態（`server` / `error` / `localOk` / `cached` / `problems`（使えないセーブ）/ `tab` / `serverBase` / `blocked`）を見られる
