# 画面に出す文章（data/text.js）

メッセージ欄・画面中央の大きい文字・頭の上に浮かぶ文字・HUD とワールドに書く文字・HTML の画面（道具一覧・店・キャラクター・クエスト・会話）・タイトルと一時停止のセーブの説明・確認のダイアログの文は、`data/text.js` の `TEXT` に置く。`src/` には文を直接書かない（言い回しを変える・別の言葉にするときは `data/text.js` だけを直す）。

## どこに何があるか

| 置き場所 | 中身 |
|---|---|
| `data/text.js` の `TEXT` | 文のひな形。まとまりごと: `combat`（技・ダメージの文・倒した）/ `units`（強化が切れた・経験値・レベルアップ・復活）/ `skills`（スキルのキーを押したが使えない）/ `items`（拾う・道具の効果と説明・使った）/ `zone`（敵レベルの範囲・入った）/ `quests`（目標の種類の文・報酬・クエストの画面）/ `menu`（道具一覧・店・キャラクターの画面）/ `talk`（会話・話しかける人がいない）/ `hud`（仲間の欄・スキル欄・行動順・地図の案内・ツールチップ）/ `world`（予告の「あと N」・敵のレベル・「!」「?」・話しかける案内・門の行き先）/ `title`（はじめの大きい文字・続きから・確認のダイアログ・歩くのをやめた）/ `save`（セーブの説明） |
| `data/theme.js` の `THEME.msg` | メッセージ欄の文の色（意味ごとの名前: `refuse` できなかった、`hurt` 主人公の陣営が受けたダメージ、`zone` ゾーンに入った など）。色を指定しない `logMsg` は `normal` |
| `data/theme.js` の `THEME.float` | 頭の上に浮かぶ文字の色と大きさ（`damage` / `miss` / `invuln` / `buff` / `exp` / `material` / `item` / `healHp` / `healMp`） |
| ほかのデータ | 敵・道具・素材・スキル・強化・クエストの名前、ステータスの表示名、NPC の名前と言葉、クエストの説明と場所、ゾーンの名前（`data/*.js`・`world.js`）。ここから文に差し込む |
| `index.html` | HTML に直接書いてある文字（タイトルの説明・操作の一覧・画面の見出し「装備中」「商品」など・「閉じる（Esc）」「再開」などのボタン・クエストの画面の操作の案内）。JS で作らない部分なので `index.html` に残す |

文と色を分けた決まり: **文は `data/text.js`、色と大きさは `data/theme.js`**（言葉を直す人が色に触らずにすむように）。拾った素材・装備の文はレア度の色、道具を使った文は最初に効いた効果の浮かぶ文字の色、強化の浮かぶ文字はその強化の色（どれもデータの色）。

## 書き方

- ひな形の `{名前}` に、`src/` が渡す値が入る（例: `heroHurt: '{src}の{what}！ {dmg} のダメージを受けた{crit}'`）。値は文字列にして入れる
- `src/` は `txt('まとまり.名前', { 名前: 値 })` で引く（`src/core.js`）。`fmt(ひな形, 値)` はひな形の文字列に値を入れるだけの道具
- 条件で文が変わるところ（主人公か・会心か・ミスか など）は、`src/` がどのひな形を使うかを選ぶ（`buffSelf` / `buffOther` のように別の名前にする）。ひな形の中に条件は書かない
- 一覧をつなぐ記号（`、` `・` ` / ` など）も `xxxSep` という名前で置いてある
- HTML の画面は、見える言葉だけをひな形にし、タグ（`<div class="…">` など）は `src/` に残す。言葉の中に色を付ける所は値として渡す（`menu.strengthNote` の `{buffed}`）
- 数の書き方（ステータスの `%` と `+` の付け方 `fmtStat`、小数の桁）は `src/` のまま

## 言い回しを変える・足す

- **変える**: `data/text.js` の文を書き換える。`{名前}` は残す（消すとその値が出なくなる。名前を変えると値が入らない）
- **足す**: 合うまとまりに名前を付けて 1 つ足し、`src/` から `txt('まとまり.名前', { … })` で引く。色が要るメッセージは `THEME.msg`（浮かぶ文字は `THEME.float`）に意味の名前で足す

## 確かめ

- `txt` は、キーがない（キーをそのまま返す）・`{名前}` に入れる値が渡されていないとき、コンソールに `[データの確認]` を 1 回だけ出す
- 起動時の `validateData` は、`TEXT` のどの文も文字列で、`{ }` が `{名前}` の形だけかを調べる
- `tests/text.test.js` が `src/*.js` の `txt('キー', { … })` を全部拾い、キーが `TEXT` にあるか、渡す値の名前と文の `{名前}` がそろっているか（多すぎも少なすぎも）を調べる

## src/ に残してよい文

- コンソールだけに出る開発用の文（`[データの確認]` の文、ITEM_EFFECTS / QUEST_GOALS / NPC_ROLES の `check` の文、セーブの `console.warn`）
- CSS のクラス名・`data-act` の値・入力の判定に使うキーの名前・`npcMark` の `'!'` / `'?'`（印の種類。書く字は `world.questMark` / `world.reportMark`）
