# ターンと速度

このゲームの中心のしくみ。数値は `params.js` の `turn`、コードは `src/turn.js`（ターンの進め方）と `src/player.js`（入力）、`src/main.js`（クリックで歩く）。

## 考え方

- 時間の単位は「ターン」。1 ターン = 速度 100 のキャラが 1 回行動するのにかかる時間（`turn.baseSpeed`）
- 主人公と敵はそれぞれ「次に行動できる時刻」（`next`）を持つ。一番早い者から行動し、行動するたびに `next` に **100 / 速度** ターンを足す
  - 速度 200 なら 0.5 ターンごと、速度 50 なら 2 ターンごとに行動できる
  - 同じ時刻なら主人公が先
- 主人公の番が来たら時間が止まり、入力を待つ（何もしなければ時間は進まない）
- 主人公の行動（移動・攻撃・スキル・回復薬・待機）はどれも 1 回分。話しかける・道具一覧を開く・装備を付け替える・壁へ動こうとするのは行動にならない

## 速度

| 誰 | 速度 |
|---|---|
| 主人公 | 100 + (すばやさ − 20) × 2（`params.js` の `derivedStats.speed`）。Lv1 で 100、Lv10 で約 124、Lv30 で約 180。装備のすばやさでも上がる |
| 敵 | 主人公と同じく、種類ごとの すばやさ（[enemies.md](enemies.md)）から計算する（すばやさ 20 で 100、1 につき +2）。すばやさは敵レベル 1 ごとに +1（`enemyLevel.agiGrowth`） |

速度の下限は 20（`turn.minSpeed`）。

速度が高いと:
- 敵が 1 回動く間に何回も動ける（逃げる・殴る・回復するが間に合う）
- 敵の技の予告（[combat.md](combat.md)）から逃げる余裕が増える

## 時間で進むもの

時間は主人公と敵の行動でだけ進む。進んだ分（ターン）だけ次のものが進む（`advanceTime`）:

- 主人公の HP 回復（HP再生 / ターン、休息中はさらに最大HP の 3% / ターン）
- 主人公の MP 回復（MP再生 / ターン、休息中はさらに最大MP の 2% / ターン）
- 湧き場所の再出現までの時間と出現予告（[world.md](world.md)）
- 落とし物が消えるまでの時間（[items.md](items.md)）

アニメーション・演出・自動セーブの間隔だけは実時間（秒）で動く。

## 仕組み

- `endPlayerAction`: 主人公が行動したあとに呼ぶ。`next` を進め、スキルの再使用までの行動回数を 1 減らし、主人公までの経路（`flow`）を作り直してから `runUntilPlayer`
- `runUntilPlayer`: `next` が一番早い敵を選び、主人公より早ければ時間をそこまで進めて `enemyAct`（[enemies.md](enemies.md)）、`next` を進める。主人公の番が来たら時間を主人公の `next` まで進めて止まる
- `turnOrder(n)`: HUD の「行動順」。主人公と、画面に入っているか追ってきている敵の `next` を写して、早い順に n 回ぶん並べる（`turn.orderCount` = 8）
- `actionsBefore(u)`: 敵 u が次に行動するまでに主人公が何回動けるか（予告の「あと N」）
- キャラの位置はマス（`tx`, `ty`）。描く位置（`x`, `y`、px）は毎フレーム、いるマスへ少し遅れて追いつく（`updateFx`。`turn.animTime`）

## 入力（`src/player.js`）

| 入力 | 行動 |
|---|---|
| WASD / 矢印 / テンキー | 1 マス移動。Q E Z C（またはテンキーの 7 9 1 3）で斜め。敵のマスへ動くと通常攻撃、NPC のマスへ動くと話しかける |
| Space / . / テンキー 5 | 1 回待つ |
| クリック | となりのマスなら移動・攻撃、自分のマスなら待つ、遠いマスならそこまで歩く |
| 1〜4 | スキルを構える。マウスで狙い、クリック・同じキー・Enter で使う。右クリック・Esc でやめる |
| R / T | 回復薬 / 上回復薬（キーは `data/items.js` の `potions` の `key`） |
| M / 右下の地図をクリック | 地図の切り替え（今いるゾーン ⇔ 世界地図）。行動にならない |

- キーを押しっぱなしにすると、`turn.repeatDelay`（0.09 秒）ごとに行動を続ける
- 遠いマスをクリックしたときは、`findPath` で道を作り、`turn.travelDelay`（0.07 秒）ごとに 1 歩ずつ歩く（`stepTravel`）。追ってきている敵が見えたとき、次のマスが予告の範囲に入っているとき、ふさがっているとき、攻撃を受けたとき、キーを押したときに止まる
- 斜めは、となりの縦横どちらかが通れない地形だと進めない（角をすり抜けない）
