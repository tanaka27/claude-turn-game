# 画面（HUD・描画）

HUD と、地面・NPC などの描画。道具一覧・店・クエストの HTML の画面はそれぞれ [menu.md](menu.md)・[progression.md](progression.md)。コードは `src/hud.js`（HUD）と `src/render.js`（ワールドの描画）。

## HUD

- 左上: 仲間の欄（`drawPartyCard`。1 人 260×72 の枠に、顔の絵（`data/player.js` の `face`。読み込めないうちは名前の 1 文字目）・名前・レベル・HP バー・MP バー（青。`THEME.mp`。小数で回復するので数字は切り捨て）だけ）。名前の右に、かかっている強化のアイコン（`drawBuffIcon`。地の色に字、右上に上昇 ▲ / 低下 ▼、右下に残りの行動回数。残り 1 で点滅。マウスを重ねると名前・効果・残りを出す `drawBuffTooltip`）。`partyMembers()` の順に上から並べる（今は主人公だけ。仲間を足したらここに加える）。欄のクリックでキャラクターの画面を開く（`hudButtons` の `char`）。経験値・撃破数・状態・ターン数・所持金・いる場所・ステータス・クエストの進み具合はフィールドには出さず、キャラクターの画面で見る（仲間が増えても画面が混まないようにするため。[menu.md](menu.md)）
- 上中央: 行動順（これから行動する順に 8 つ。「自」が主人公、ほかは敵の字。主人公の陣営のキャラは青い枠、敵は赤い枠。予告中の敵は枠がオレンジ）。その下に、ボスが追ってきているときだけボスの HP バー（画面が狭いと左上の仲間の欄と重なるので、欄の下に下げる）
- 画面中央: ゾーンに入ったとき、ゾーン名と敵レベルの範囲を大きく表示。レベルアップ・クエスト達成も
- 左下: メッセージ欄（新しい 7 行。古いものほど薄い。`log`）
- 下中央: スキル欄（主人公の `skillSlots` の並び。今は 1〜5。下にキー、まん中にスキルの名前。再使用までの残りを時計回りの影と行動回数で表示。まだ覚えていないスキル（`knowsSkill`）は暗くして「LvN で解放」（覚えるレベルがないスキルは「未習得」）。右上に消費 MP（「MP3」。足りないときは赤 `THEME.mpShort` で、枠も暗くする））。続けて回復薬（R）と上回復薬（T）。残りの数を右上に表示。右端は「道具」ボタン（黄色の枠。クリックで道具一覧を開く。マウスを重ねると明るくなり、カーソルが指の形になる）。クリックできる HUD のボタンは `drawHUD` が毎回 `hudButtons` に位置を入れ、`hudButtonAt` でクリック（`src/player.js` の mousedown）を振り分ける
- 右下: ミニマップ（障害物、門、かがり火、NPC、敵（追ってきている敵は明るい赤）、出現予告、主人公の陣営のほかのキャラ（水色の小さな四角）、主人公、今見えている範囲）。M キーか地図のクリックで世界地図に切り替わる（もう一度で戻る。地図の上に「M: 世界地図」「M: このエリアの地図」と案内を出す。切り替えた状態はセーブしない）
- 世界地図（`drawWorldMap`）: 全ゾーンを `world.js` の `mapPos` の位置に並べ、それぞれの地形・門・かがり火・NPC と、門どうしをつなぐ線、枠の下にゾーン名と敵レベル（町は「安全地帯」）を描く。ゾーンの大きさは実際の比率（町は小さく出る）。今いるゾーンは枠と名前を水色にし、主人公の位置を出す（建物の中のゾーンは描かず、中にいるときは外のゾーンの入口に出す）。敵は描かない。スキル欄の右と上中央の行動順（`HUD_TOP`）の下に収まるように枠を縮める（文字は縮めない。`WORLD.worldMap`。[world.md](world.md)）
- 右下の地図は `hudButtons` に `map` として入れ、クリックを `toggleWorldMap` に振り分ける
- マウスを重ねた敵の情報（速度と、自分の速度の何倍か）。NPC なら名前・種類とステータス（「攻撃は当たらない」と出す）

## ワールドの描画

- 地面に薄くマス目の線を引く。障害物はマスにそろえた範囲で描く
- マウスを重ねているマスに枠（スキルを構えている間は濃く）。クリックで歩いている間は道を点で出す
- 敵の技の予告: 範囲のマスを赤く塗り、主人公に一番近いマスに「あと N」（1 のときは点滅）。投げる技は投げる者から着弾点へ点線
- 自分のスキルを構えている間: 当たる範囲のマスを白く塗る（メテオは届く範囲を点線の円で、ダッシュは進むマスを）
- 判定が出たとき: 範囲のマスが一瞬光る。弾は線の上を先端が走り、投げたものは放物線で落ちて輪が広がる
- 主人公: 絵（`data/player.js` の `sprite`）で描き、足元に水色（主人公の `color`）の輪。強化・弱体がかかっていると頭上に小さいアイコンを並べる（`drawBuffRow`。敵・仲間も同じで、頭上の HP バーのさらに上に並べる）。左を向くと左右反転、当たると白く光る。絵がなければ丸と剣の線
- 敵: 絵（`sprite`）で描く。当たった瞬間は同じ形の白で光り、ボスは足元に金の輪。絵がなければ丸い体・耳・目・字（[enemies.md](enemies.md)）。絵は `getSprite` が最初に使うときに読み込む（起動時のデータの確認で読み込みを始める）
- 敵の頭上: レベル（レベル差で色分け）と HP バー（帰還中は灰色。絵のときは絵の上端の上）。予告中は「!」
- 出現予告: 紫のマス（だんだん濃くなる）
- 落とし物: 素材は色付きのひし形、装備は宝箱（レア度の色。レア以上は光る）。消える 20 ターン前から点滅
- 門: 水色の枠。行き先の名前と敵レベルを出す。建物の入口（`door: true`）は扉の下を少し光らせ、家の上に建物の名前だけを出す（[buildings.md](buildings.md)）
- NPC: 名前と、となりのマスにいるときは「F: 話しかける」。頭上に、受けられるクエストがあれば黄色の「!」、報告できるクエストがあれば緑の「?」
- キャラはマスを移ると、描く位置が少し遅れて追いつく（なめらかに動いて見える）
