# 画面（HUD・描画）

HUD と、地面・NPC などの描画、道具一覧の画面。持ち物・店・クエストの HTML の画面はそれぞれ [items.md](items.md)・[progression.md](progression.md)。コードは `src/hud.js`（HUD）と `src/render.js`（ワールドの描画）、`src/catalog.js`（道具一覧）。

## HUD

- 左上: HP バー、経験値バー、レベル、撃破数、状態（安全地帯／休息中／戦闘中）、ゲーム内のターン数、所持金、ゾーン名と敵レベルの範囲
- 上中央: 行動順（これから行動する順に 8 つ。「自」が主人公、ほかは敵の字。予告中の敵は枠がオレンジ）。その下に、ボスが追ってきているときだけボスの HP バー
- 画面中央: ゾーンに入ったとき、ゾーン名と敵レベルの範囲を大きく表示。レベルアップ・クエスト達成も
- 右上: 主人公のステータス一覧（ちから〜うんのよさ、こうげき力、しゅび力、速度、会心率。並び順・表示名・桁数は `data/stats.js` の `hud`）。その下に、受けているクエストの進み具合（報告できるものは緑）
- 左下: メッセージ欄（新しい 7 行。古いものほど薄い。`log`）
- 下中央: スキル欄（1〜4。再使用までの残りを時計回りの影と行動回数で表示。まだ使えないスキルは暗くして「LvN で解放」）。右端は回復薬（R）と上回復薬（T）。残りの数を右上に表示
- 右下: ミニマップ（障害物、門、かがり火、NPC、敵（追ってきている敵は明るい赤）、出現予告、主人公、今見えている範囲）
- マウスを重ねた敵の情報（速度と、自分の速度の何倍か）

## ワールドの描画

- 地面に薄くマス目の線を引く。障害物はマスにそろえた範囲で描く
- マウスを重ねているマスに枠（スキルを構えている間は濃く）。クリックで歩いている間は道を点で出す
- 敵の技の予告: 範囲のマスを赤く塗り、主人公に一番近いマスに「あと N」（1 のときは点滅）。投げる技は投げる者から着弾点へ点線
- 自分のスキルを構えている間: 当たる範囲のマスを白く塗る（メテオは届く範囲を点線の円で、ダッシュは進むマスを）
- 判定が出たとき: 範囲のマスが一瞬光る。弾は線の上を先端が走り、投げたものは放物線で落ちて輪が広がる
- 敵の頭上: レベル（レベル差で色分け）と HP バー（帰還中は灰色）。予告中は「!」
- 出現予告: 紫のマス（だんだん濃くなる）
- 落とし物: 素材は色付きのひし形、装備は宝箱（レア度の色。レア以上は光る）。消える 20 ターン前から点滅
- NPC: 名前と、となりのマスにいるときは「F: 話しかける」。頭上に、受けられるクエストがあれば黄色の「!」、報告できるクエストがあれば緑の「?」
- キャラはマスを移ると、描く位置が少し遅れて追いつく（なめらかに動いて見える）

## 道具一覧の画面（`src/catalog.js`）

回復薬・素材・装備の図鑑。L キー（一時停止中も）か、一時停止画面の「道具一覧」ボタンで開く。閉じる（Esc / L / 閉じる）と、開いたときに一時停止していれば一時停止画面に戻る。HTML は `index.html` の `#catalog`。`menu.mode` は `'catalog'`（ほかの画面と同じく `game.state = 'menu'` で時間は止まる）。

- 上のタブで切り替える（`catalog.tab`: `potion` / `material` / `gear`。閉じても覚えている）
- 回復薬: 効果（今の最大HPなら何回復か）、使うキー、値段、所持数 / 持てる数、売っている店（町と NPC の名前）
- 素材: 全素材の表（売値・所持数・所持分の合計・落とす敵と確率・その敵が出るゾーン）。持っていない素材は薄く出す。下に所持素材の売値の合計
- 装備: 部位ごとの名前の段階（装備レベルの範囲と、その最初のレベルでのノーマルの基本性能）、売っている店とレア度。最後にレア度の表と追加性能の候補（Lv1 の値）
- 中身はすべて `data/items.js`（`ITEMS`）・`data/enemies.js`（`drops`）・`world.js`（NPC の `shop`、湧き場所の `members`）から作る。データを足せば一覧にも自動で出る
