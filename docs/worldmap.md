# 世界地図（M キー・拡大・ドラッグ）

右下の地図を世界地図に切り替えると、ワールドマップ全体を縮めて描く。拡大・縮小・ドラッグで動かす・画面いっぱいに大きく出すことができる。コードは `src/hud.js`（`drawWorldMap` / `toggleWorldMap` / `zoomWorldMap` / `panWorldMap` / `worldMapView`）と `src/player.js`（キー・マウス）。大きさの数値は `world.js` の `WORLD.worldMap`。ワールドマップそのものは [overworld.md](overworld.md)。

## 操作

| 操作 | 動き |
|---|---|
| M | 今いるゾーンの地図 → 世界地図（右下）→ 世界地図（大きく）→ ゾーンの地図 の順に切り替える |
| 右下の地図をクリック | ゾーンの地図なら世界地図にする。世界地図なら右下 ⇔ 大きく を切り替える（動かさずに離したとき） |
| 世界地図の上でホイール | 拡大・縮小（カーソルの下の場所を動かさない）。1 回で `zoomStep` 倍 |
| + / - （; / = / テンキーの + -） | 世界地図を出している間、拡大・縮小（地図のまん中を中心に） |
| 世界地図をドラッグ | 見ている場所を動かす（4 px より動かすとドラッグ。そのときは大きさを切り替えない） |

どれも行動にならない（時間は進まない）。世界地図を開くと、見ている場所のまん中を主人公（町・ダンジョン・建物の中ならその入口）にする。切り替えた状態・倍率はセーブしない。

## 描き方

- 地形は一度だけ 1 マス = 1 px の別のキャンバスに描いておき（`worldMapCanvas`）、拡大して貼る（にじませない）。地図の枠の外ははみ出さないように切り取る（`clip`）
- 倍率: 全体がちょうど枠に収まる大きさを 1 として、`zoom` 倍（1〜`maxZoom`）。見ている場所のまん中（`cx`, `cy`、ワールドマップの px）は、地図の外を映さないように描くたびに寄せる（倍率 1 なら地図のまん中）
- 地方の名前を薄く、入口に印（町は四角、ダンジョンは三角、倒れたときに戻る町はかがり火の色）と名前を出す。枠の外の入口は描かない。敵は描かない
- 枠の上に案内（`TEXT.hud.mapHintZoom` / `mapHintBig`。今の倍率も出す）
- 右下: 最大 `maxW` 480 × `maxH` 320 px。スキル欄の右と上中央の行動順（`HUD_TOP`）の下に収まるように、`minScale` 0.5 倍まで縮める（文字は縮めない）
- 大きく: 行動順の下からスキル欄の上までの画面のまん中に、全体が収まる大きさで出す。左上の仲間の欄と重ならないように、欄の横を左右同じ幅だけ空けるか、欄の下から出すかの、地図が大きくなるほうにする。文字と印も少し大きくする
- 最後に描いた地図の場所と倍率は `worldMapView.panel`（`mx`, `my`, `mw`, `mh`, `s`）に置き、ホイール・ドラッグの計算に使う

## パラメータ（`WORLD.worldMap`）

| 名前 | 値 | 意味 |
|---|---|---|
| `maxW` / `maxH` | 480 / 320 | 右下に出すときの最大の大きさ（画面 px） |
| `minScale` | 0.5 | 画面が狭いときに右下の地図を縮める下限 |
| `maxZoom` | 8 | 拡大の上限（全体が収まる大きさの何倍まで） |
| `zoomStep` | 1.25 | ホイール 1 回・+ / - 1 回の倍率 |
