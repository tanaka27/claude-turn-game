ターン制

町を出て魔物を倒し、経験値を集めてレベルを上げよう。
草原 → 森 → 遺跡と、門をくぐって奥へ進むほど敵は強くなる。
町は 3 つ。町ごとに店の品ぞろえが違い、倒れると最後に立ち寄った町に戻る。

WASD / 矢印1 マス移動（Q E Z C で斜め。テンキーも使える） 敵へ移動その敵を攻撃する（通常攻撃） クリックとなりのマスなら移動・攻撃、遠くのマスならそこまで歩く（敵に気づかれると止まる） Space / .その場で 1 ターン待つ 1 / 2 / 3 / 4スキルを構える → マウスで狙ってクリック（同じキー / Enter でも可。右クリック・Esc でやめる） R / T回復薬 / 上回復薬を使う（上回復薬は森の隠れ里で買える） I持ち物（装備の付け替え・捨てる） L道具一覧（回復薬・素材・装備の図鑑。落とす敵や売っている店が分かる） Fとなりの人に話しかける（人のいるマスへ移動しても話しかける） Esc / P一時停止（一時停止中に C でキャラクターの画面） マウスを敵に重ねる敵のレベル・速度などを表示（名前の色: 赤＝格上、灰＝格下）
敵の技の予告 自分のスキルの範囲 敵の出現予告

あなたが行動すると時間が進み、敵も動きます。行動しなければ時間は止まったままです。
速度（すばやさで上がる）が高いほど、敵が 1 回動く間に何回も行動できます。画面上の「行動順」で確かめよう。
強い技は赤い予告が出て、使った敵の次の番に当たります。「あと N」はそれまでにあなたが動ける回数です。
壁は移動と攻撃を遮り、水場・柵は移動のみを遮ります。町は安全地帯。倒れると町のかがり火で復活します（所持金を少し失います）。
素材は町の商人に売るとお金になります。衛兵隊長の頼みを聞いて報酬を得よう。光る床（門）で隣のゾーンへ。進行は自動で保存されます。
